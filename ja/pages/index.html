Empasyとは？ (What is Empasy?)

Empasyは4-Tier 9種エンタープライズ自律型AIエージェントエコシステムを提供するソフトウェア企業です。

Empasy SyncSeries 9 Solutions

  • SyncVerse: Tier 1 全社AI自律運営統合管制塔。
  • SyncInsight: Tier 1 マルチエージェント討論・戦略意思決定支援プラットフォーム。
  • SyncLLM: Tier 2 マルチLLMゲートウェイ・セマンティックキャッシュ・FinOps/PII保護。
  • SyncBoot: Tier 2 Spring Boot 3.5 MSA自動構築・Saga補償トランザクションエージェント。
  • SyncCMS: Tier 3 Nuxt 3 SSRハイブリッドCMS・3-Agent Swarmパブリッシャー。
  • SyncShop: Tier 3 分散マイクロサービスEC・pgvectorセマンティック検索エージェント。
  • SyncOps: Tier 3 SI事業運営・デュアル単価損益・KOSA稼働率・4大保証保険・下請法60日監視・電子研究ノート統合管制プラットフォーム。
  • SyncEta: Tier 4 Vision-LLM自己修復E2E QAテスト自動化エージェント。
  • SyncCrawl: Tier 4 動的DOM対応・アンチボット回避RAGデータ収集エージェント。

Core Architecture & Safety

Spec-First 自律エンジニアリング & ガードレール

仕様書の先行承認と実行時自己修復により、AIコード生成の信頼性と安全性を保証します。

3大実行トラック (Triple Execution Tracks)

Track 1 • No-Code Data

コンテンツ＆データ自律反映

コード変更が不要なブログ・商品カタログ・設定変更は、専門エージェント(SyncCMS, SyncShop)が直接自律処理します。

Track 2 • Direct Patch

AST構文解析＆自己修復PR

単一コンポーネントや軽微なUI不具合は、AST構文解析を通じて自動パッチを生成し、E2Eテスト検証後にGitHub PRを作成します。

Track 3 • Spec-First HITL

企画・設計仕様書の先行承認

大規模な機能追加時にはコードを直接書かず、企画書(PRD) → API/DB仕様 → 画面仕様を先行承認した上で一括実装します。

Vision-LLM Engine

DOM構造やクラス名が変更されても、画面レイアウトとテキスト文脈からUI要素を再識別しテスト実行を自己修復(Self-Healing)します。

FinOps & PII Guardrail

SyncLLMにより個人情報をリアルタイムでマスキングし、Redisセマンティックキャッシュと日次予算Capでトークン費用の急増を防止します。

Saga Pattern MSA Control

マイクロサービスに分散した環境で障害が発生した際、事前定義された補償トランザクションを自動実行しデータ整合性を維持します。

Emergency Kill-Switch

異常検知時にはワンクリックで全エージェントの書き込み権限を剥奪し、システムを読み取り専用隔離モードへ切り替えます。
