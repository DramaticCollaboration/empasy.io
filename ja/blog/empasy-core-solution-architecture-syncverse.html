SyncSeriesは、Empasyの企業向けソフトウェア群を共通の技術基盤（Java 25、Spring Boot 4.0、PostgreSQL 18.6 pgvector、Vue 3 / Nuxt 3、Playwright、MCP/A2A）上に整理したモジュール型プラットフォームです。本記事では4つの中核業務領域と7つの拡張モジュールが解決する現場課題を全体構成から解説します。

1. SyncETA：クリック記録と自己修復による画面自動点検

現場のボトルネック

頻繁なUI改修によりボタンIDや配置が変わるたび、従来のE2Eテストスクリプトが破損し、リリース前の検証と修正に多大な工数がかかります。

設計アプローチ

  • クリック操作からのExcelシナリオ生成：操作イベントとDOMアクセシビリティツリーを取得し、非エンジニアでも編集できる標準Excel形式の点検手順へ変換します。
  • Playwrightによる決定論的な高速並列実行：定常的な回帰テストでは外部LLMを呼び出さず再生エンジンで実行し、反復実行コストを抑えます。
  • 自己修復（Self-Healing）と品質ゲート：画面構造の変化で要素が見つからない場合のみ文脈解析で代替ロケータを補完し、負荷・カオス検証とあわせて品質ゲートを判定します。

2. SyncCMS：特定製品に依存しない多言語Webサイト統合基盤

現場のボトルネック

国別・ブランド別のWebサイトが分散していると、文言修正やキャンペーン公開のたびに開発部門のリリース待ちが発生します。

設計アプローチ

  • Spring Boot + Nuxt 3 SSR ハイブリッドヘッドレス：高いSEO性能とRESTful APIによる柔軟な外部連携を両立します。
  • 3-Agent コンテンツ検収フロー：執筆・SEO/アクセシビリティ/広告表記チェック・承認後公開を一貫管理し、本番反映は必ず担当者承認を経ます。
  • 単一管理画面でのマルチサイト統制：拠点ごとの権限分離、コンテンツモデル継承、版管理を1画面で行えます。

3. SyncBoot：組織権限・電子決裁・動的設定を備えた社内業務基盤

現場のボトルネック

社内システムを新設するたびに認証、組織権限、電子決裁、監査ログを一から作り直すと、納期遅延と保守の属人化を招きます。

設計アプローチ

  • 業務共通機能の標準装備：組織・役職連動RBAC（メニュー・ボタン単位）、多段階電子決裁、データポータル、監査ログを標準提供します。
  • DB駆動の動的設定・プロンプトハブ：運用設定（sys_config）やAIプロンプト（sys_prompt_template）を再起動なしで更新し、ClusterEventBroadcasterで全インスタンスへ即時同期します。
  • 分散信頼性と可観測性：SagaCoordinatorによる補償処理、Trace ID追跡、Slow SQL検知を備えています。

4. SyncVerse：要件整理から段階別承認までをつなぐ中央管制ハブ

現場のボトルネック

個別にAIツールを導入しても、依頼・コード差分・テスト結果・承認履歴が分散していると、変更統制と監査対応が困難になります。

設計アプローチ

  • MCPベースのA2A統括連携：標準プロトコルとセキュリティ認証のもとで各業務エージェントへタスクを委任し、結果を統合報告します。
  • 5-Step Spec Studio と15種コーディング基盤ルーティング：受入基準整理からAPI設計、SyncSDKによるブランチ・PR作成、4-Cycle品質検証まで構造化します。
  • 多段階承認（Multi-Party HITL）と3段階ハーネス：高リスク変更は開発・QA・セキュリティ担当者の承認を経て反映されます。

5. SyncInsight：社内閉域環境を守る経営データ照会

現場のボトルネック

部門ごとに分断されたERPデータや機密文書は、情報漏えい懸念から外部パブリックAIへ直接投入できません。

設計アプローチ

  • オンプレミス・閉域網対応：データ基盤とローカルLLMランタイム（vLLM、Ollama等）を社内サーバーや専用VPC内に配置できます。
  • 読み取り専用NL2SQLファイアウォール＆ハイブリッドRAG：Apache CalciteとJSqlParserでSELECT専用制御を徹底し、pgvector + BM25 + ナレッジグラフで根拠付き回答を生成します。
  • 分析から実行への安全な連携：表・グラフ・要因分析を提示し、承認された改善アクションをSyncVerseへ引き継ぎます。

6. 共通コア上に拡張できるその他の専門モジュール（SyncInsight除く6種）

上記で解説したSyncInsightに加え、同じ共通基盤モジュール上で必要に応じて次の6種の拡張モジュールを組み合わせられます。

  • SyncLLM：意味キャッシュ、部門別予算上限、個人情報マスキング、マルチモデル自動迂回を備えたAIゲートウェイ。
  • SyncCrawl：robots.txt遵守、Playwrightロケータ自己修復、ノイズ除去で社内検索向け文書を整える収集基盤。
  • SyncShop：9つの独立MSA構成で最低利益率保護とスナップショット即時復元を提供するEC運用基盤。
  • SyncOps：単価別損益ピボット、保証証券期限、下請法支払期限（15日/60日）を自動監視する事業運営基盤。
  • SyncAPIM：構文トークン解析、シャドーAPI検知、正常トラフィック検証済み仮想パッチとeBPF防御を行うAPIセキュリティ基盤。
  • SyncWatch：国内外の脆弱性情報（NVD、CISA KEV、KISA等）を収集・検証し、SyncVerse監査パックとSyncAPIM防御パックを同時配信する脅威インテリジェンス基盤。
