機械語（JSON）からビジネス言語（Excel）へ：SyncETAのインテリジェント回帰テストパイプライン

ソフトウェアのデプロイ周期が「週単位」から「日単位」へと短縮されるアジャイル(Agile)およびクラウドネイティブ環境において、品質保証(QA)は依然として最も多くの手作業とリソースのボトルネックが発生する領域です。UIの小さな変更(DOM構造、ID/Class属性など)でも既存のE2Eテストスクリプトが簡単に壊れてしまう「メンテナンスの地獄(Maintenance Hell)」は、自動化の最大の障害でした。

EmpasyのSyncETAはこれらの限界を克服するため、「Boon to business by agility」というビジョンの下、AI自動生成から無人自律運用段階までを網羅するEnd-to-Endの循環型品質エコシステム(Self-Evolving AI First QA Platform)を構築しました。本記事では、SyncETAのコアアーキテクチャと最新のエンジニアリング高度化の成果について深く掘り下げます。

1. インテリジェントな5大レイヤーアーキテクチャのデータフロー

SyncETAは、非構造化されたユーザー行動ログを精密に収集し、自ら進化する5つのコア階層構造で構成されています。

LAYER 01
データ収集
ブラウザイベントおよびDOM Contextの精密キャプチャ (Seleniumベース) ➔ Machine Log / JSON format
LAYER 02
AI プロセッシング
LLM Semantic Parserを通じた自然言語(Excel)テストケース生成 ➔ 国際標準Excelテンプレート
LAYER 03
検証と循環
QAエンジニアのフィードバックループ (LoRAファインチューニング / システム自己進化) ➔ 確定した自然言語コマンド
LAYER 04
インテリジェント実行
Playwright MCPベースのバックグラウンドヘッドレス超高速並列分散実行 ➔ 失敗スナップショット & .webmビデオマッピング
LAYER 05
監視と分析
リアルタイムダッシュボードモニタリングおよびWeb Result Viewerストリーミング

コアとなる差別化要因：年間LLM費用の99%を削減するアーキテクチャ

既存のAIツールとは異なり、SyncETAは「シナリオ生成時にのみLLMを1回活用」し、その後の実際のテスト実行段階ではLLM APIの呼び出しなしに決定論的なレコード再生エンジンを通じて実行されます。これにより、エンタープライズ環境で数千回繰り返される回帰テストのコストを最大99%革新的に削減します。

2. 主要なエンジニアリング高度化の成果

① Headless Automation Pipeline & 外部システム連動 (RESTful API)

外部システムやCI/CDパイプラインから自然言語コマンドテキストを送信するだけで、即座にバックグラウンドでテストを完走する完璧な無人自動化ループを提供します。

  • Inbound インターフェース (POST /api/v1/execute/natural-language): 外部からプロジェクトIDと自然言語シナリオを受信すると、内蔵されたLLMエンジンが文脈を分析し、Login → Navigate → Verify Element 構造のPlaywright-MCPコマンドにリアルタイムで変換します。
  • 動画エビデンスの自動マッピング: ブラウザを画面に表示しないHeadlessモードで高速並列起動しながら、実行の全過程を.webm形式の映像でリアルタイム録画し、テスト終了後にAWS S3バケットに自動アップロードし、固有のPublic URLとPass/Fail状態ログを外部のCallback URLに即座に返します(Outbound API)。

3. エンタープライズ導入の成果と期待効果

  • QA設計と作成工数を80%削減: 国際標準フォーマットの自然言語Excel形式でコミュニケーションできるため、コーディング知識のない現場担当者や企画者(PL)でも即座に品質資産を設計し検証できる「QAの民主化」環境を提供します。
  • セキュリティファーストのローカルLLMエコシステム: 企業の機密データやテスト環境情報の流出リスクを防ぐため、Dockerベースの完全な社内閉鎖網オンプレミス(On-premise)および隔離クラウドハイブリッドインフラアーキテクチャによるローカルLLMモデルの構築を完全にサポートします。

SyncETAは、Webエコシステムの精密検証性能を基盤として、単一の自然言語シナリオでAndroidとiOSを同時制御できるUniversal Locator構造ベースの「モバイル領域への拡張(DeviceHub連動)」技術開発マイルストーンを実現しています。QAのパラダイムを変えるSyncETAの高度化された新技術は、Empasy公式技術ブログを通じて継続的に共有される予定です。
