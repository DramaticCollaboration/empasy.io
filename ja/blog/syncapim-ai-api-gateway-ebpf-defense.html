シャドーAPI検知から無停止仮想パッチ・eBPF防御まで：SyncAPIM セキュリティガイド

経営層・現場担当者のための3行要約
  • 従来の課題ルール肥大化した従来型正規表現WAFは応答遅延を招きやすく、未登録シャドーAPI経由の個人情報流出を把握できません。
  • 解決アプローチSyncAPIMは構文トークン解析と正常トラフィック検証済みの仮想パッチを無停止適用し、eBPFカーネル遮断と応答PII自動マスクを一体運用します。
  • 導入効果アプリの緊急再デプロイを待たずに新規脆弱性を防御し、全API資産と通信トポロジーの可視性を確保できます。

マイクロサービス化と外部API連携の拡大に伴い、サイバー攻撃の主戦場はAPIエンドポイントへ移っています。従来の正規表現ベースWAFはルール増加による遅延や難読化攻撃のすり抜け、さらに仕様書に存在しないシャドーAPIからの情報漏えいに対応しきれない課題があります。

EmpasyのSyncAPIMは、構文トークン解析、実トラフィックからのOpenAPI自動抽出、リプレイ検証済み仮想パッチ、eBPFカーネル防御、応答PIIマスクを1つのゲートウェイへ統合しています。

1. SyncAPIM 4段階ランタイム防御パイプライン

2. 正規表現の限界を超える構文トークン解析

SqlXssLexicalTokenizerは入力を構文トークン列へ分解して攻撃パターンを判定するため、コメント挿入や多重エンコードによる回避攻撃にも強く、インライン処理性能を安定維持します。

3. シャドーAPI自動発見と応答PIIマスキング

  • OpenAPI 3.0.1 自動リバースエンジニアリング：実通信から未登録APIや過剰レスポンスを自動検出し、仕様と実態のズレを可視化します。
  • 8種個人情報の応答マスク：ホワイトリスト（/waf/pii_whitelist）に基づき、応答データ内の機密個人情報を自動マスクします。

4. SyncWatch連携仮想パッチとeBPFカーネルトポロジー

  • 誤遮断を抑えた仮想パッチ配信：SyncWatchから配信されるApimDefensePackを正常業務通信でリプレイ検証してからRedis経由で無停止適用します。
  • eBPF資産・接続可視化：軽量eBPFエージェントがランタイムSBOM（/waf/asset）と通信トポロジー（/waf/topology）を描画し、悪性発信元をカーネル層で即座に遮断します。
