업무의 변화

기존 방식과 무엇이 다른가요?

간단한 집계 하나를 뽑기 위해 개발팀에 매번 데이터 추출을 요청하던 불편을 줄이고, 현업 담당자가 직접 안전하게 데이터를 탐색할 수 있도록 돕습니다.

기존 데이터 확인 방식

  • − 정해진 대시보드에 없는 조건을 보려면 개발팀이나 데이터 팀에 추출을 요청하고 며칠을 기다려야 합니다.
  • − 전문 검색식을 쓰기 어려워 실무자가 엑셀로 수작업 병합을 반복하게 됩니다.
  • − 지표가 어떤 업무 데이터에서 어떻게 계산된 숫자인지 출처를 확인하기 어렵습니다.

SyncInsight 도입 후

  • ✓ "지난 분기 카테고리별 매출 추이 보여줘"처럼 일상 언어로 질문하면 조회 결과와 차트를 바로 확인합니다.
  • ✓ 읽기 전용 조회만 허용해 실수로 운영 데이터를 수정하거나 삭제할 위험을 막아 줍니다.
  • ✓ 생성된 조회 조건과 데이터가 어디서 왔는지 흐름도를 함께 보여 주어 결과를 검증할 수 있습니다.

주요 기능

SyncInsight로 할 수 있는 일

01

한국어 질문 기반 데이터 조회 및 차트

질문을 입력하면 조회 조건을 자동 작성해 표와 차트로 보여 주며, 사용된 조회 조건도 투명하게 확인할 수 있습니다.

02

원인 요약 리포트 작성 지원

단순 합계 조회를 넘어 기간별 변동 요인과 관련 자료를 함께 정리해 보고서 초안 작성을 돕습니다.

03

여러 업무 데이터 연결 및 출처 추적

여러 사내 업무 데이터를 한곳에 연결하고, 각 지표가 어떤 원본 데이터에서 산출되었는지 흐름도로 확인합니다.

이렇게 사용합니다

STEP 01

읽기 전용 데이터 연결

운영 데이터나 분석용 데이터를 읽기 전용 권한으로 안전하게 연결합니다.

STEP 02

일상 언어로 질문 입력

궁금한 매출·주문·운영 지표를 한국어로 입력하거나 추천 질문을 선택합니다.

STEP 03

차트·근거 확인 및 공유

자동 생성된 표와 차트, 조회 근거를 확인하고 보고서나 회의 자료로 활용합니다.

직접 체험

설치 없이 실제 화면을 눌러 보세요

SyncInsight는 SyncVerse 통합 콘솔 안에서 제공되며, 체험 데이터는 매일 오전 4시에 초기화됩니다.

1. 체험 화면 열기

SyncVerse 통합 분석 콘솔

SyncVerse 관리 콘솔 내 [데이터 분석] 메뉴에서 한국어 데이터 질문, 분석 보고서, 데이터 흐름, DB 연결을 통합 체험합니다.

분석 화면 열기 ↗
SyncVerse 통합 워크스페이스 데이터 질문

SyncVerse 통합 워크스페이스에서도 동일한 대화형 데이터 조회를 바로 실행할 수 있습니다.

워크스페이스 조회 ↗

2. 체험 계정 복사

총괄 관리자 (공통) 기본 체험 계정

SyncVerse 내 데이터 질문, 분석 보고서, 데이터 흐름, 연결 DB 설정 전체 메뉴를 체험합니다.

다른 역할 계정 보기 (1개)
데이터 분석·기획 담당자

DB 연결 설정을 제외한 대화형 데이터 조회, 요약 리포트, 데이터 출처 지도를 체험할 수 있습니다.

로그인 후 확인해 볼 3가지

01 데이터 분석 > 대화형 조회

샘플 질문으로 표와 차트 확인

제공된 예시 질문을 클릭하거나 직접 질문을 입력해 표와 차트가 만들어지는 과정을 확인하세요.

02 데이터 분석 > 분석 보고서

요약 분석 리포트 확인

단순 수치를 넘어 변동 요인을 정리해 주는 보고서 화면을 살펴보세요.

03 데이터 분석 > 출처 흐름

데이터 출처 지도 탐색

지표가 어떤 업무 데이터에서 연결되어 나오는지 관계도를 눌러 확인해 보세요.

도입 안내

조직 상황에 맞춰 필요한 만큼만 시작하세요

전체 시스템을 한꺼번에 바꿀 필요 없이, 현재 가장 시급한 업무 영역부터 단독으로 적용할 수 있습니다.

읽기 전용 데이터 연결로 안전하게 시작

기존 운영 시스템의 복제본이나 분석용 데이터를 읽기 전용으로만 연결해 원본 변경 걱정 없이 바로 조회를 시작합니다.

현업 부서별 권한·질문 범위 설정

영업·재무·운영 부서별로 볼 수 있는 지표와 테이블 범위를 나누어 실무자가 직접 보고서용 숫자를 뽑아 쓸 수 있습니다.

외부 유출 없는 폐쇄망 분석 구축

SyncLLM의 개인정보 가림 또는 사내 전용 서버 AI와 결합해 매출·고객 데이터가 외부로 나가지 않게 운영합니다.

자주 묻는 질문

잘못된 질문으로 사내 운영 데이터가 수정되거나 지워질 위험은 없나요?
읽기 전용 조회만 실행되도록 제한되어 있으며, 데이터를 변경하거나 삭제하는 명령은 실행 단계에서 차단됩니다.
AI가 계산한 숫자가 맞는지 어떻게 확인할 수 있나요?
차트와 함께 실제로 사내 업무 데이터에서 조회한 조건 원문과 원본 표 데이터를 그대로 보여 주어 담당자가 직접 검증할 수 있습니다.
사내 데이터가 외부 AI 서비스로 나가지 않게 운영할 수 있나요?
네. 사내망 구축 환경이나 SyncLLM의 민감정보 가림 기능과 결합해 외부 유출 걱정 없이 운영할 수 있습니다.

개발·인프라 담당자를 위한 상세 아키텍처와 연동 규격은 기술 문서 포털에서 확인하실 수 있습니다.
