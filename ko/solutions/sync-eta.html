업무의 변화

기존 방식과 무엇이 다른가요?

국가별·상품별 페이지가 수백 개인 운영 사이트에서도 대표·표본 주소만으로 폭넓게 AI 테스트 자동화를 실행하고, UI 개편 시 깨진 셀렉터를 자가 치유하며, 확인된 것만 정상으로 기록하고 애매한 화면은 사진과 함께 [확인 필요]로 정직하게 분류합니다.

지금 (수작업 QA 방식)

  • − 수백 개 국가·상품 페이지 중 시간 부족으로 대표 페이지 한두 곳만 수동 확인하고, 화면이 조금만 바뀌면 기존 스크립트가 깨집니다.
  • − 금융 보안 가상 키보드나 글로벌 쿠키 동의 팝업 앞에서 점검이 멈추며, 글자 겹침과 404 하위 링크를 눈으로 하나씩 찾아야 합니다.
  • − 놓치고 못 본 요소가 정상으로 넘어갈 위험이 있고, 문제를 찾을 때마다 캡처해 엑셀에 정리한 뒤 수정 후 처음부터 다시 눌러야 합니다.

SyncETA 도입 후

  • ✓ 대표·표본 주소만으로 여러 국가·상품 페이지를 폭넓게 점검하고, 동작 녹화·엑셀·한 줄 문장 변환과 변경 위치 자동 찾기를 지원합니다.
  • ✓ 보안 가상 키패드·쿠키 배너를 자동 통과하고, 시나리오 없이도 하위 링크 404와 글자 겹침·화면 깨짐을 전수 검사합니다.
  • ✓ 확인한 것만 정상 집계하며 애매한 화면은 [확인 필요]로 분리하고, 사진 첨부 버그 칸반 티켓에서 [지금 확인] 버튼 하나로 재검증합니다.

주요 기능

SyncETA로 할 수 있는 일

01

브라우저 동작 레코더

클릭·입력·스크롤을 실시간 기록해 재사용 블록으로 저장하며, 보안 가상 키패드 자동 인식, 글로벌 쿠키 배너 닫기, 민감 개인정보 마스킹을 지원합니다.

02

엑셀 및 한 줄 문장 테스트 변환

기존 엑셀·CSV 시험표를 업로드하거나 한 줄 문장으로 즉시 점검을 구성하며, 대표·표본 주소 사전 실행과 대화형 실시간 방향 조정으로 오류를 방지합니다.

03

멀티 계정 동시 테스트

고객 화면과 관리자 화면처럼 서로 다른 계정 2개를 독립 로그인 세션으로 동시에 띄워 실시간 상호작용과 역할별 오류 로그를 한 번에 검증합니다.

04

링크 전수 검사 및 화면 디자인 진단

시나리오 없이도 사이트 지식그래프로 하위 링크 404·의미 불일치·글자 겹침·빈 영역·미디어 재생 오류를 찾아내고, 화면 개편 시 변경된 버튼 위치도 자동으로 찾습니다.

05

버그 칸반 보드 및 [지금 확인] 재검증

문제 사진이 첨부된 티켓을 자동 생성해 대기→아직 있음→해결됨→종료 단계로 관리하며, 중복 발권 차단·[버그가 아닙니다] 영구 기억·원클릭 즉시 재검증을 제공합니다.

06

정직한 [확인 필요] 분류 및 정기 스케줄러

확실히 확인한 것만 정상으로 기록하고 애매한 화면은 사진과 함께 분리하며, 새벽·배포 직후 정기 자동 실행과 Jira·Jenkins·GitHub Actions·Slack 연동을 지원합니다.

이렇게 사용합니다

STEP 01

1단계 · 점검 시나리오 준비

브라우저 클릭 동작을 녹화하거나 기존 엑셀 시험표·한 줄 문장으로 점검을 구성하고, 표본 주소 사전 검증으로 오류를 미리 막습니다.

STEP 02

2단계 · 자동 실행 및 화면 판정

실제 브라우저로 하위 링크와 글자 겹침·화면 깨짐을 전수 검사하고, 화면이 바뀌어도 버튼을 스스로 찾아 정상·결함·[확인 필요]로 분류합니다.

STEP 03

3단계 · 결함 티켓 및 원클릭 재검증

실패 순간의 녹화 영상·한글 원인 요약과 사진이 담긴 버그 칸반 티켓을 관리하고, 조치 완료 후 [지금 확인] 버튼 하나로 즉시 재검증합니다.

도입 안내

조직 상황에 맞춰 필요한 만큼만 시작하세요

전체 시스템을 한꺼번에 바꿀 필요 없이, 현재 가장 시급한 업무 영역부터 단독으로 적용할 수 있습니다.

1단계 (2~4주) · 대상 사이트 1곳 시범 구성

운영 중인 웹 시스템 1곳을 골라 동작 녹화와 엑셀 문서 기반 점검을 준비하고, 대표·표본 주소로 공통 점검 기준을 설정합니다.

2단계 (4~8주) · 정기 자동 점검 & 버그 칸반 운용

정기 회귀 점검과 링크·화면 전수 검사를 가동하고, 버그 칸반 [지금 확인] 재검증과 수작업 시간 절감율을 직접 측정합니다.

3단계 (확대) · 전사 사이트 확장 & 업무 도구 연동

효과를 확인한 뒤 다른 웹 서비스로 넓히고, Jira·Jenkins·GitHub Actions·Slack 알림 및 사내 폐쇄망 운영으로 정착시킵니다.

자주 묻는 질문

기존 Selenium·Playwright나 AI 코딩 도구와 SyncETA AI 테스트 자동화의 차이는 무엇인가요?
기존 스크립트 도구(Selenium·Playwright)는 개발자가 코드를 직접 작성하고 UI 변경마다 셀렉터를 수동 수정해야 하며, AI 코딩 도구는 코드 초안 작성에 집중되어 매 실행·수정에 개발자 개입이 필요합니다. SyncETA는 기획자·QA 담당자도 코딩 없이 클릭 녹화·엑셀·한 줄 문장으로 E2E 시나리오를 만들고, 평상시 반복 회귀 테스트는 LLM 토큰 비용 없이 Playwright로 고속 재생하며, UI가 바뀌어 셀렉터가 깨질 때만 Vision-LLM과 DOM 문맥으로 자가 치유(Self-Healing)합니다.
개발자가 아닌 QA 담당자나 서비스 운영자도 바로 쓸 수 있나요?
네. 브라우저에서 평소처럼 클릭한 동작을 그대로 녹화하거나, 기존 엑셀 시험표 업로드 및 '하위 링크 검사해줘', '화면 깨짐 봐줘' 같은 한 줄 문장만으로 자동 점검을 실행할 수 있습니다.
금융 보안 가상 키패드나 해외 사이트 쿠키 동의 팝업이 떠도 동작하나요?
네. 보안 가상 키패드 자동 인식 입력과 글로벌 쿠키 동의 배너 자동 닫기를 기본 지원하며, 주민번호·전화번호 같은 민감 개인정보는 자동으로 가림(마스킹) 처리합니다.
도입 효과는 과장 없이 어떻게 확인할 수 있나요?
대표·표본 URL 다중 점검, 시나리오 없는 링크·겹침 검출, 보안 키패드·쿠키 통과, 영상·사진 포함 티켓 발권, [지금 확인] 원클릭 재검증은 도입 즉시 확인 가능합니다. 시간 절감율과 사전 결함 검출 수는 운영 사이트 1곳에 2~4주 시범 적용해 실제 숫자로 함께 측정합니다.
이미 운영 중인 웹사이트나 사내 폐쇄망 시스템에도 적용되나요?
네. 기존 웹사이트 코드를 고칠 필요 없이 주소만 등록하면 바로 점검할 수 있으며, 데스크톱 앱 로컬 실행이나 사내 온프레미스 서버 설치로 외부 접속이 차단된 내부망·VPN 시스템도 안전하게 점검합니다.
이미 쓰고 있는 Jira, Jenkins, GitHub Actions, Slack과 연결되나요?
네. 자체 버그 칸반 보드 외에 Jira 이슈 연동, Jenkins·GitHub Actions 배포 파이프라인 연동, Slack·이메일 결과 통지를 모두 지원합니다.

개발·인프라 담당자를 위한 상세 아키텍처와 연동 규격은 기술 문서 포털에서 확인하실 수 있습니다.
