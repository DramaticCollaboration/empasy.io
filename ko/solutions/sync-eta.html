What is Empasy SyncEta?

SyncEta is a Self-Healing QA (Quality Assurance) Agent developed by Empasy. Powered by Vision-LLM, it completely replaces fragile, script-based legacy testing tools like Selenium by visually understanding user interfaces like a human tester.

Key Features of SyncEta

  • Self-Healing Automation: Automatically updates its own test scripts when a website's UI or DOM structure changes, eliminating test maintenance overhead.
  • Vision-LLM Testing: Evaluates not just code, but visual aesthetics, layout integrity, and functional workflows purely through visual understanding.
  • Natural Language Test Generation: Create complex end-to-end test scenarios simply by describing them in everyday language.

SyncEta ensures zero-defect software delivery by acting as an autonomous QA team that works 24/7, radically improving software reliability and release velocity.

핵심 기능 (Key Features)

👁️

Vision LLM 시각 인식

단순한 DOM 구조(XPath/CSS) 의존을 탈피합니다. AI가 사람처럼 화면을 '보고' 버튼의 위치나 디자인이 변경되어도 정확히 대상 엘리먼트를 추적합니다.

🩹

실시간 자가 치유 (Self-Healing)

테스트 실행 중 UI 식별자가 깨진 것을 발견하면, 에이전트가 화면 문맥을 분석하여 새로운 식별자를 스스로 찾고 코드를 수정하여 테스트를 완주합니다.

📝

자연어 기반 시나리오 자동 생성

사용자 스토리나 기획서를 업로드하면, AI가 BDD(Behavior-Driven Development) 스타일의 테스트 시나리오와 Playwright 스크립트를 자동 생성합니다.

자주 묻는 질문 (FAQ)

기존 테스트 스크립트 도구(Selenium 등)와 무엇이 다른가요?
SyncEta는 UI 디자인이 변경되어도 Vision-LLM이 스스로 새로운 요소를 찾아내어 테스트를 자가 치유합니다.
웹과 모바일 뷰 모두 지원하나요?
네, 웹 브라우저 기반 테스트뿐 아니라 다양한 디바이스 환경에서의 반응형 테스트를 모두 지원합니다.
QA 리소스 절감 효과는 어느 정도인가요?
테스트 스크립트 유지보수에 들어가던 인력과 시간을 80% 이상 절감할 수 있습니다.
