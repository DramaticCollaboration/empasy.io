SyncEta

화면 레이아웃 문맥을 인지하고 셀렉터 장애를 자가 복구하는 UI 테스트 자동화 솔루션입니다.

데스크탑 앱 다운로드 엔터프라이즈 데모 신청

기존 스크립트 기반 QA

  • UI 디자인 또는 DOM 구조 변경 시 고정 식별자 오류로 테스트 실패
  • 단순 픽셀 비교로 인한 오탐(False Positive) 빈번 발생
  • UI 릴리즈마다 테스트 스크립트 수동 수정에 많은 공수 투입

SyncEta 에이전트

  • Vision-LLM을 활용한 시각적 식별자 자동 탐색 및 자가 복구
  • 텍스트와 레이아웃 문맥 기반의 기능 검증
  • 테스트 실패 시 실패 원인 분석 및 수정 스크립트 자동 제안
Technical Proof

Self-Healing 코드 자가 복구 동작 방식

버튼 클래스명이 변경되어도 Vision-LLM이 문맥을 분석하여 스크립트를 실시간 패치합니다.

// Playwright Test Execution: tests/checkout.spec.ts

핵심 기능 및 기술 아키텍처

01

Vision-LLM 자가 복구 (Self-Healing)

단순 XPath/CSS 의존을 탈피하여, 화면 내 컴포넌트의 위치와 텍스트 레이블 문맥을 종합 판단하여 깨진 셀렉터를 런타임에 실시간 자가 치유합니다.

02

엑셀(Excel) 테스트케이스 직결 자동 실행

별도의 레코딩이나 스크립트 코딩 없이, 기존 QA팀이 보유한 엑셀 기반 테스트케이스를 AI가 자동 해석하여 Playwright 자동화 테스트로 즉시 실행합니다.

03

L1~L5 계층별 심층 품질 검증

L1(단순 렌더링/클릭)부터 L3(캐러셀·추천상품 등 동적 런타임 변수 캡처), L5(API 요청/응답 트랜잭션 및 페이지 정체성 검증)까지 다차원 품질을 보증합니다.

04

연간 LLM 비용 최대 99% 절감 (TCO)

테스트 시나리오 생성 시에만 1회 LLM을 호출하고, 반복 회귀 테스트는 녹화된 엔진 레코드로 무비용 구동하여 엔터프라이즈 운영 비용을 획기적으로 낮춥니다.

자주 묻는 질문 (FAQ)

기존 테스트 도구(Selenium, Playwright)와 호환되나요?
네, 기존 Playwright 및 Selenium 테스트 스크립트 위에 래퍼 형태로 구동되어 자가 복구(Self-Healing) 레이어만 추가할 수 있습니다.
웹과 반응형 모바일 환경을 모두 지원하나요?
데스크톱 브라우저뿐 아니라 다양한 모바일 뷰포트 해상도 환경에서의 시각적 회귀 테스트를 지원합니다.
사내 폐쇄망(On-Premises) 환경에서도 구동 가능한가요?
네, 엔터프라이즈 라이선스 고객을 위해 사내 VPC 및 에어갭 폐쇄망 내 프라이빗 LLM 인프라 배포를 지원합니다.
