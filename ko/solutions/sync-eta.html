핵심 기능 및 기술 아키텍처

01

Vision-LLM 자가 복구
(Self-Healing)

단순 XPath/CSS 의존을 탈피하여, 화면 내 컴포넌트의 위치와 텍스트 레이블 문맥을 종합 판단하여 깨진 셀렉터를 런타임에 실시간 자가 치유합니다.

02

엑셀(Excel) 테스트케이스
직결 자동 실행

별도의 레코딩이나 스크립트 코딩 없이, 기존 QA팀이 보유한 엑셀 기반 테스트케이스를 AI가 자동 해석하여 Playwright 자동화 테스트로 즉시 실행합니다.

03

L1~L5 계층별 심층 품질 검증

L1(단순 렌더링/클릭)부터 L3(캐러셀·추천상품 등 동적 런타임 변수 캡처), L5(API 요청/응답 트랜잭션 및 페이지 정체성 검증)까지 다차원 품질을 보증합니다.

04

연간 LLM 비용 최대 99% 절감 (TCO)

테스트 시나리오 생성 시에만 1회 LLM을 호출하고, 반복 회귀 테스트는 녹화된 엔진 레코드로 무비용 구동하여 엔터프라이즈 운영 비용을 획기적으로 낮춥니다.

자주 묻는 질문 (FAQ)

코딩 경험이 없는 QA나 기획자도 바로 사용할 수 있나요?
네, 스크립트 코딩 없이 브라우저 조작 녹화만으로 테스트 시나리오를 자동 생성할 수 있습니다. 또한 기존에 팀에서 관리하던 엑셀(Excel) 테스트케이스를 불러와 바로 자동화 테스트로 구동할 수 있습니다.
화면 UI나 버튼 위치가 바뀌면 테스트 스크립트를 매번 다시 짜야 하나요?
아닙니다. 화면의 텍스트와 레이아웃 문맥을 종합 파악하여 요소 위치나 클래스명이 변경되어도 대상을 스스로 찾아 실행을 이어갑니다. 릴리즈마다 반복되던 스크립트 수정 공수를 대폭 줄일 수 있습니다.
기존에 사용하던 테스트 도구(Playwright, Selenium)나 엑셀 자산도 유지되나요?
기존 테스트 자산을 폐기할 필요가 없습니다. Playwright 및 Selenium 파이프라인 위에 바로 연동하여 문맥 인식 복구 기능을 더할 수 있으며, 엑셀로 작성된 수동 검증 목록도 즉시 자동 실행 목록으로 전환됩니다.
스마트폰, 태블릿 등 모바일 반응형 환경도 함께 검증되나요?
데스크톱 브라우저뿐만 아니라 스마트폰, 태블릿 등 기기별 해상도 환경을 지원합니다. 화면 크기별 레이아웃 깨짐이나 사용자 플로우가 정상 작동하는지 한 번의 실행으로 교차 검증할 수 있습니다.
사내 보안망이나 로컬(localhost) 개발 환경에서도 안심하고 쓸 수 있나요?
외부 클라우드로 내부 데이터나 화면 정보가 유출되지 않도록 로컬 PC 및 사내 폐쇄망(에어갭) 환경에서의 독립 구동을 지원합니다. 로컬 개발 서버 URL도 제한 없이 안전하게 테스트 가능합니다.
