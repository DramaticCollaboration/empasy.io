  • 본문 수정 시 글로벌 다국어 번역 리소스 및 pgvector 시맨틱 인덱스 자동 동기화

핵심 기능 및 기술 아키텍처

01

Copywriter-SEO-Publisher 스웜

페이지 목적과 구성 요소를 자연어로 전달하면 AgentScope 기반 3대 에이전트 스웜이 본문 초안, JSON-LD 메타데이터, UI 컴포넌트 블록을 자율 조립합니다.

02

글로벌 다중 로케일 동기화

단일 관리 콘솔에서 한국어, 영어, 일본어 등 다국어 채널을 관리하며, 기준 콘텐츠 수정 시 다국어 번역 자원을 문맥에 맞게 일괄 갱신합니다.

03

Nuxt 3 SSR + Spring Boot
하이브리드 아키텍처

Spring Boot 백엔드(`/api/v1/cms`)와 Nuxt 3(Vue 3) SSR 프론트엔드 및 Vben Admin 백오피스를 결합하여 초고속 서버 사이드 렌더링과 엔터프라이즈 보안을 동시에 보장합니다.

04

Adobe InDesign 지식그래프 연동 (Web + Print)

전용 InDesign 플러그인과 지식그래프 파이프라인을 통해 웹 콘텐츠와 출판 인쇄 조판 데이터를 단일 소스로 일체화 동기화합니다.

작동 프로세스 (How it Works)

1

요구사항 입력

페이지 기획안 또는 원하는 섹션 구조를 텍스트로 에이전트에게 전달합니다.

2

3-Agent 스웜 레이아웃 및 콘텐츠 생성

Copywriter·SEO·Publisher 에이전트가 디자인 시스템 컴포넌트를 조립하고 SEO 메타데이터와 본문 콘텐츠를 생성합니다.

3

다국어 검수 및 Nuxt 3 SSR 배포

로케일별 번역 상태를 확인하고 Nuxt 3 SSR 및 글로벌 CDN 캐시를 통해 무중단 배포합니다.

자주 묻는 질문 (FAQ)

비개발자도 신규 페이지를 제작할 수 있나요?
네, 기획자가 자연어 명령과 프리뷰 화면을 통해 컴포넌트를 배치하고 콘텐츠를 편집할 수 있습니다.
다국어 번역 리소스는 어떻게 관리되나요?
원문 수정 시 연결된 로케일 리소스 번역이 백그라운드에서 동기화되며, 관리자 검수를 거쳐 반영됩니다.
기존 사내 레거시 시스템과 연동 가능한가요?
표준 REST API(`/api/v1/cms`) 인터페이스를 제공하여 기존 사내 데이터베이스 및 SSO 인증 체계와 연동할 수 있습니다.
