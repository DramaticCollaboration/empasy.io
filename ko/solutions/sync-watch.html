SyncWatch

전 세계 8대 공식 보안 기관(CISA, NVD, KISA 등)의 신규 취약점 정보를 24시간 자동으로 수집해 우리 회사 시스템의 영향도를 즉시 진단하고, 개발 코드 점검 규칙(SyncVerse)과 실시간 API 차단 규칙(SyncAPIM)을 동시에 생성·배포하는 전사 보안 관측소입니다.

기존 수동 보안 권고 모니터링 및 개별 대응

  • NVD, CISA, KISA 등 다수의 보안 권고 사이트를 담당자가 수작업으로 확인하고 영향도를 분석해야 함
  • 신규 제로데이 발표 후 개발팀의 코드 패치와 보안팀의 WAF 차단 규칙 작성이 분리되어 방어 공백 발생
  • 검증되지 않은 방화벽 정규식을 긴급 배포했다가 정상 API 요청까지 차단하는 오탐 장애 발생

SyncWatch 자동 보안 관제 도입 후

  • 국내외 8대 보안 기관의 취약점 정보와 사내 진단 문서를 한곳으로 안전하게 자동 수집·정리
  • 신규 취약점 발견 즉시 개발 코드 점검 규칙(SyncVerse)과 실시간 API 차단 규칙(SyncAPIM)을 동시에 자동 생성
  • 정상 업무 요청이 잘못 차단되지 않도록 사전 안전 검증(오탐 0% 확인)을 통과한 방어 규칙만 전사에 즉시 배포

신규 취약점 수집부터 코드 점검·실시간 차단까지 3단계 자동 방어

01

신규 보안 취약점 24시간 자동 수집 및 사내 영향도 진단

미국 CISA·NVD, 한국 KISA 등 국내외 보안 경보와 사내 모의해킹 보고서를 자동으로 수집·정리하고, 우리 회사가 사용 중인 소프트웨어에 영향이 있는지 즉시 대조합니다.

02

개발 단계 보안 점검 및 패치 코드 자동 제안 (SyncVerse 연동)

새로 확인된 취약점을 막기 위한 코드 점검 규칙(VerseAuditPack)을 생성해 사내 소스코드 저장소를 자동으로 검사하고 안전한 수정 코드를 제안합니다.

03

운영 서버 무중단 실시간 공격 차단 (SyncAPIM 연동)

정상 요청 오차단이 없는지 가상 환경에서 먼저 검증한 뒤, 실시간 API 게이트웨이 차단 규칙(ApimDefensePack)을 배포하여 서버 재시작 없이 즉시 공격을 방어합니다.

작동 순서

1

국내외 최신 보안 취약점 및 진단 문서 자동 수집

8대 글로벌 보안 채널과 사내 진단 보고서를 실시간으로 수집하여 위험도와 영향 범위 기준으로 일목요연하게 정리합니다.

2

방어 규칙 자동 생성 및 오차단 방지 사전 검증

개발 코드 점검용 규칙과 운영 API 차단용 규칙을 동시에 만들고, 실제 공격은 100% 막고 정상 업무는 방해하지 않는지 안전하게 사전 테스트합니다.

3

전사 시스템 무중단 배포 및 방어 현황 관제

검증을 마친 방어 규칙을 전사 개발·운영 환경에 즉시 적용하고, 조치 완료 현황과 실시간 차단 이력을 대시보드에서 한눈에 추적합니다.

자주 묻는 질문 (FAQ)

신규 CVE 위협이 발표되면 방어 룰이 얼마나 빠르게 배포되나요?
글로벌 보안 채널(NVD, CISA KEV, OSV.dev, GHSA, KISA 등)에서 신규 취약점이 수집되는 즉시 정규화 및 샌드박스 검증을 거쳐, 수분 이내에 SyncVerse 코드 점검 팩과 SyncAPIM 런타임 가상 패치 팩으로 동시 배포됩니다.
자동 생성된 보안 룰이 정상 운영 트래픽을 잘못 차단(False Positive)할 위험은 없나요?
SyncWatch는 컴파일된 룰을 즉시 배포하지 않고, 내장 샌드박스 검증기에서 공격 페이로드(Positive) 100% 탐지와 정상 업무 요청(Negative) 0% 오탐을 먼저 통과한 룰만 전사로 브로드캐스트합니다.
사내 자체 보안 진단 결과 보고서나 KISA 권고 문서도 등록할 수 있나요?
네. 외부 자동 피드뿐만 아니라 사내 모의해킹 결과서나 보안 권고 문서를 업로드하면 CWE·MITRE 기준 보안 이슈로 정규화하여 동일한 듀얼 보안 룰로 컴파일·배포할 수 있습니다.
