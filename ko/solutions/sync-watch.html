SyncWatch

글로벌 보안 위협(NVD CVE, CISA KEV, OSV.dev, GitHub GHSA, Nuclei, OWASP CRS, KISA) 및 보안 진단 문서를 단일 허브로 수집·정규화하여, SyncVerse에는 코드·의존성·모의해킹 보안 점검 팩(VerseAuditPack)을, SyncAPIM에는 런타임 공격 패턴 팩(ApimDefensePack)을 실시간 컴파일·배포하는 전사 보안 관측소입니다.

실시간 데모 체험 도입 문의하기

기존 수동 보안 권고 모니터링 및 개별 대응

  • NVD, CISA, KISA 등 다수의 보안 권고 사이트를 담당자가 수작업으로 확인하고 영향도를 분석해야 함
  • 신규 제로데이 발표 후 개발팀의 코드 패치와 보안팀의 WAF 차단 규칙 작성이 분리되어 방어 공백 발생
  • 검증되지 않은 방화벽 정규식을 긴급 배포했다가 정상 API 요청까지 차단하는 오탐 장애 발생

SyncWatch 3각 자율 DevSecOps 도입 후

  • 7대 글로벌 보안 피드와 진단 문서를 5단계 SSRF 가드 아래 단일 허브로 자동 수집·정규화
  • WatchRuleCompilerService가 SyncVerse용 VerseAuditPack과 SyncAPIM용 ApimDefensePack을 동시 컴파일
  • Positive/Negative 샘플 기반 자체 샌드박스 검증(TP 100%, FP 0%) 통과 룰만 전사로 즉시 브로드캐스트

3각 자율 DevSecOps 보안 아키텍처

01

SyncWatch (위협 수집 & 듀얼 룰 컴파일)

NVD CVE, CISA KEV, OSV.dev, GitHub GHSA, Nuclei, OWASP CRS, KISA 위협 피드와 보안 진단 문서를 수집·정규화하고 자체 샌드박스 검증을 거쳐 듀얼 보안 팩을 컴파일합니다.

02

SyncVerse (Shift-Left 코드 보안 점검 & 자동 패치 PR)

SyncWatch가 배포한 VerseAuditPack(SCA 의존성 범위, SAST 코드 정규식, DAST 모의해킹 프로브)을 수신해 전사 저장소를 점검하고 보안 패치 PR을 자동 생성합니다.

03

SyncAPIM (Shift-Right 런타임 공격 패턴 차단)

SyncWatch가 배포한 ApimDefensePack(구문 토큰 지문, 타깃 위치별 정규식, Restricted SpEL)을 SandboxedDefenseEvaluator로 무중단 반영하여 런타임 공격을 즉시 차단합니다.

작동 순서

1

7대 글로벌 위협 피드 및 보안 진단 문서 수집·정규화

외부 보안 피드 출처(watch_feed_source)와 진단 문서를 수집해 CWE·MITRE·생태계 기준 보안 이슈 원장(watch_security_advisory)으로 정규화합니다.

2

VerseAuditPack & ApimDefensePack 듀얼 컴파일 및 샌드박스 검증

코드 점검 룰과 런타임 방어 룰을 동시에 컴파일하고, 공격(Positive)·정상(Negative) 샘플 페이로드로 오탐 여부를 자체 검증합니다.

3

SyncVerse · SyncAPIM 실시간 브로드캐스트 배포 및 피드백 관제

검증된 보안 팩을 전사로 즉시 배포하고, 저장소 코드 감사 결과와 API 게이트웨이 실시간 차단 피드백을 배포 원장(watch_dispatch_history)에서 추적합니다.
