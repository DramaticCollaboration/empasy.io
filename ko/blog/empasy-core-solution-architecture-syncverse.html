하나의 공통 기반 위에 구성된 SyncSeries 핵심 제품군 한눈에 보기

경영진 · 현업 담당자를 위한 3줄 요약
  • 기존 문제부서마다 서로 다른 소프트웨어를 따로 도입하면 계정·권한·데이터가 단절되어 운영과 통합 비용이 빠르게 증가합니다.
  • 해결 방식협업·승인(SyncVerse), 자동 화면 점검(SyncETA), 사내 관리 시스템(SyncBoot), 다국어 웹사이트(SyncCMS)와 7대 확장 모듈을 하나의 공통 코어 위에 정리했습니다.
  • 기대 효과지금 필요한 1개 영역부터 가볍게 도입하고, 추후 다른 업무를 연결할 때도 동일한 권한·감사 체계로 확장할 수 있습니다.

이 글의 목차
  1. 1. SyncETA: 클릭 녹화와 자가 치유 기반 자동 화면 점검
  2. 2. SyncCMS: 개발자 종속을 줄이는 다국어 웹사이트 통합 플랫폼
  3. 3. SyncBoot: 표준 권한·결재·동적 설정을 갖춘 사내 업무 시스템 코어
  4. 4. SyncVerse: 요구사항부터 승인·배포까지 잇는 중앙 오케스트레이션
  5. 5. SyncInsight: 사내 보안 경계 안에서 작동하는 경영 데이터 조회
  6. 6. 목적별 확장 모듈 한눈에 보기 (SyncInsight 외 6종)

SyncSeries는 엠파시의 기업 업무 소프트웨어를 하나의 공통 기술 스택(Java 25, Spring Boot 4.0, PostgreSQL 18.6 pgvector, Vue 3 / Nuxt 3, Playwright, MCP/A2A) 위에 정렬한 모듈형 플랫폼입니다. 이 글에서는 4대 핵심 업무 영역과 의사결정·운영·보안을 보완하는 7대 확장 모듈이 각각 어떤 현장 병목을 해결하는지 아키텍처 관점에서 정리합니다.

1. SyncETA: 클릭 녹화와 자가 치유 기반 자동 화면 점검

현장 병목: UI 변경마다 깨지는 회귀 테스트 스크립트

프론트엔드 개편이 잦은 웹·모바일 서비스에서는 버튼 ID나 레이아웃이 조금만 바뀌어도 기존 E2E 스크립트가 실패해 QA 유지보수 비용이 급증합니다.

엔지니어링 해법

  • 클릭 녹화 및 엑셀 시나리오 변환: 브라우저 상호작용과 DOM 접근성 트리 구조를 캡처해, 코딩 경험이 없는 실무자도 편집 가능한 표준 엑셀(Step-Input-Expected Result) 테스트케이스로 정리합니다.
  • Playwright 기반 고속 병렬 실행: 일상적인 반복 회귀 실행은 결정론적 Playwright 재생 엔진으로 수행해 반복 실행 시 불필요한 LLM API 비용을 발생시키지 않습니다.
  • 셀렉터 자가 치유(Self-Healing) 및 품질 게이트: UI 구조가 변경돼 기존 식별자를 찾지 못할 때만 DOM 문맥을 분석해 대체 로케이터를 보정하며, 카오스·부하 시뮬레이션과 함께 배포 품질 게이트 판정을 지원합니다.

2. SyncCMS: 개발자 종속을 줄이는 다국어 웹사이트 통합 플랫폼

현장 병목: 다중 브랜드·다국어 사이트 운영과 배포 대기

글로벌 법인이나 브랜드별 사이트가 분산되어 있으면 단순 문구 수정이나 캠페인 페이지 개설에도 개발 배포 일정을 기다려야 합니다.

엔지니어링 해법

  • Spring Boot + Nuxt 3 SSR 하이브리드 헤드리스: 개방형 Spring Boot 백엔드와 Nuxt 3(Vue 3 SSR) 프론트엔드를 결합해, 높은 검색엔진 최적화(SEO) 성능과 RESTful API 기반 확장성을 동시에 확보합니다.
  • 3-Agent 콘텐츠 검수 워크플로우: 초안 작성(Copywriter), 검색·접근성·표시광고 점검(SEO/Reviewer), 승인 후 발행(Publisher) 흐름을 지원하며, 모든 라이브 반영은 담당자 검토를 거쳐 실행됩니다.
  • 단일 콘솔 멀티사이트·다국어 제어: 여러 브랜드와 다수의 다국어 웹사이트를 하나의 백오피스에서 사이트별 권한·콘텐츠 모델·버전 이력과 함께 관리합니다.

3. SyncBoot: 표준 권한·결재·동적 설정을 갖춘 사내 업무 시스템 코어

현장 병목: 매 프로젝트마다 반복되는 공통 기반 개발

새 사내 시스템을 구축할 때마다 로그인, 조직도·직책별 권한, 한국형 전자결재, 감사 이력, 설정 관리 기능을 매번 새로 개발하면 초기 구축 기간과 유지보수 부채가 커집니다.

엔지니어링 해법

  • 엔터프라이즈 공통 기능 내장: 조직도 연계 RBAC(메뉴·버튼 단위 권한), 다단계 전자결재, 멀티 게시판, 데이터 포털, 감사 로그를 표준 모듈로 제공합니다.
  • DB 기반 동적 설정·프롬프트 허브: 운영 정책(sys_config)과 AI 프롬프트(sys_prompt_template)를 코드 재배포 없이 관리하고, ClusterEventBroadcaster로 멀티 인스턴스 캐시를 즉시 동기화합니다.
  • 안정적 트랜잭션 및 관측성: SagaCoordinator 기반 보상 처리와 Trace ID·Slow SQL 추적을 기본 지원해 장애 원인을 빠르게 파악합니다.

4. SyncVerse: 요구사항부터 승인·배포까지 잇는 중앙 오케스트레이션

현장 병목: 메신저·문서·코드·테스트·승인의 단절

개별 AI 도구를 도입하더라도 요구사항 정의, 코드 변경, 테스트 결과, 관리자 승인 이력이 제각각 흩어져 있으면 감사 대응과 변경 통제가 어렵습니다.

엔지니어링 해법

  • MCP 기반 A2A 통합 관제: 표준 MCP 프로토콜과 인바운드 보안 인증을 통해 각 도메인 에이전트에게 작업을 위임하고 실행 결과를 통합 브리핑합니다.
  • 5-Step Spec Studio 및 15대 코딩 엔진 라우팅: 요구사항 수용 기준(AC) 정제부터 화면·API 설계, SyncSDK(15대 엔터프라이즈 코딩 엔진 핫스왑) 기반 브랜치·PR 생성, 4-Cycle 품질 검증까지 구조화합니다.
  • 다자간 승인 결재선(Multi-Party HITL) 및 3단계 하네스: 코드 변이나 스키마 변경 같은 고위험 작업은 개발·QA·보안·관리자 단계별 승인을 거쳐야 반영됩니다.

5. SyncInsight: 사내 보안 경계 안에서 작동하는 경영 데이터 조회

현장 병목: 외부 클라우드 유출 우려와 사일로화된 사내 데이터

ERP, 사내 위키, 외부 시장 데이터가 부서별로 고립되어 있고 보안 규정상 퍼블릭 LLM에 원본 데이터를 올릴 수 없어 경영진과 현업의 즉시 조회가 어렵습니다.

엔지니어링 해법

  • 온프레미스·폐쇄망 우선 아키텍처: 저장소와 로컬 LLM 런타임(vLLM, Ollama 등)을 사내 서버나 전용 VPC 내부에 배치해 민감 데이터의 외부 반출을 통제합니다.
  • 읽기 전용 NL2SQL 방화벽 & 3중 하이브리드 RAG: Apache Calcite·JSqlParser 기반 SELECT-Only 방화벽으로 안전하게 정형 DB를 조회하고, sync-module-rag(pgvector + BM25 + 지식 그래프)로 문서 근거를 교차 검증합니다.
  • 멀티 에이전트 분석 및 실행 연계: 수집·분석·보고 에이전트가 표·차트와 원인 요약을 제시하고, 담당자가 승인한 실행 과제를 SyncVerse로 전달합니다.

6. 목적별 확장 모듈 한눈에 보기 (SyncInsight 외 6종)

4대 핵심 영역과 앞서 살펴본 SyncInsight에 더해, 동일한 공통 모듈(sync-core, sync-module-ai, sync-module-rag, sync-module-nl2sql, sync-module-audit, sync-module-deploy) 위에서 필요에 따라 아래 6종 확장 모듈을 조합할 수 있습니다.

  • SyncLLM: 부서별 AI 예산 한도, 의미 기반 캐시, 8대 개인정보 마스킹, 다중 모델 우회 라우팅을 제공하는 AI 게이트웨이.
  • SyncCrawl: robots.txt 준수, Playwright 셀렉터 자가 치유, 노이즈 제거를 거쳐 사내 검색용 문서를 정제하는 웹 데이터 수집 파이프라인.
  • SyncShop: 9대 독립 마이크로서비스(MSA) 구조 위에 최소 마진율 보호와 스냅샷 원클릭 롤백을 제공하는 이커머스 운영 엔진.
  • SyncOps: KOSA 기술등급 듀얼 단가 손익 피벗과 하도급법(15일/60일) 지급기한·보증증권 만기를 자동 감시하는 사업운영 플랫폼.
  • SyncAPIM: 구문 토큰 지문 분석, 섀도우 API 탐지, 정상 트래픽 백테스팅 기반 무중단 가상 패치와 eBPF 커널 방어를 수행하는 API 보안 게이트웨이.
  • SyncWatch: 글로벌 주요 보안 피드(NVD, CISA KEV, KISA 등)를 수집·검증해 SyncVerse 코드 감사 팩과 SyncAPIM 방어 팩으로 동시 배포하는 보안 인텔리전스 허브.
SyncSeries 전체 제품군 브로셔와 라이브 데모를 확인해 보세요 11개 모듈이 공통 로그인·권한·감사 기반 위에서 어떻게 연결되는지 실제 화면으로 살펴볼 수 있습니다.
