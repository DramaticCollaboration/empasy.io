사내 보안 환경을 지키는 경영 데이터 조회: SyncInsight 안전 분석 가이드

경영진 · 현업 담당자를 위한 3줄 요약
  • 기존 문제외부 클라우드 전송이 금지된 보안 환경에서는 경영진과 현업이 데이터를 바로 조회하기 어려워 매번 IT 부서에 추출을 요청해야 합니다.
  • 해결 방식외부와 차단된 사내 서버 안에서 일상 한국어로 질문하면 읽기 전용 NL2SQL 방화벽과 하이브리드 RAG로 안전하게 표·차트와 원인 요약을 제공합니다.
  • 기대 효과원본 데이터 유출 우려 없이 의사결정 속도를 높이고, 승인된 개선 과제만 SyncVerse 실행 흐름으로 안전하게 연계합니다.

ERP, 그룹웨어, 사내 위키, 정산 DB, 외부 시장 지표 등 기업의 핵심 데이터는 부서별 시스템에 흩어져 있습니다. 경영진과 현업이 빠르게 현황을 파악하고 싶어도, 보안 규정상 민감한 데이터를 퍼블릭 클라우드 LLM에 직접 올릴 수 없어 매번 IT 부서에 SQL 추출과 엑셀 가공을 요청해야 하는 병목이 반복됩니다.

엠파시의 의사결정 인텔리전스 엔진인 SyncInsight는 사내 서버·전용 VPC 경계 내부에서 정형 DB와 비정형 문서를 안전하게 교차 분석하고, 표·차트·근거 인용이 포함된 리포트를 제공합니다.

1. 사내망 내재화 우선(On-Premise First) 보안 아키텍처

SyncInsight는 데이터 저장소, 벡터 색인(PostgreSQL 18.6 pgvector), 로컬 LLM 서빙 환경(vLLM, Ollama 등)을 기업 내부 사설망이나 전용 격리 VPC 안에 배치할 수 있도록 설계되었습니다. 외부 클라우드로의 원본 전송 없이 금융·공공·제조 환경의 엄격한 내부 통제 기준에 맞춰 운영할 수 있습니다.

2. 읽기 전용 NL2SQL 방화벽 & 3중 하이브리드 RAG

자연어 질의를 실제 사내 데이터베이스에 연결할 때 가장 우려되는 지점은 잘못된 변경 쿼리 실행과 근거 없는 추측(환각)입니다. SyncInsight는 두 계층의 안전장치를 결합합니다.

  • Apache Calcite + JSqlParser 기반 SELECT-Only 방화벽(sync-module-nl2sql): 생성된 SQL의 구문 트리를 파싱해 INSERT, UPDATE, DELETE, DROP 등 모든 쓰기·스키마 변경 구문을 실행 전 단계에서 차단하고, 허용된 테이블·컬럼 범위 내 읽기 전용 조회만 통과시킵니다.
  • 3중 하이브리드 RAG(sync-module-rag): 사내 위키·정책 문서와 SyncCrawl이 정제한 외부 시장 자료를 pgvector(의미 검색) + BM25(정확 키워드) + Knowledge Graph(관계 탐색)로 통합 색인해 근거 출처와 함께 응답합니다.

3. 멀티 에이전트 교차 분석(Deep Research) 파이프라인

단순 단답형 조회를 넘어 원인 분석과 대안 비교가 필요한 경영 질문에는 역할이 분리된 3단계 분석 파이프라인이 협업합니다.

STEP 01
수집 에이전트 (Collector)
NL2SQL 안전 조회와 사내·외부 RAG 근거 데이터 수집
→
STEP 02
교차 분석 에이전트 (Analyst)
지표 변동 원인 분해, 구간별 추세 및 이상치 비교 분석
→
STEP 03
리포트 에이전트 (Reporter)
근거 출처가 포함된 표·차트 및 경영 요약 리포트 생성
  • Collector Agent: 인가된 RBAC 범위 내의 내부 지표와 정제된 외부 시장 데이터를 취합합니다.
  • Analyst Agent: 기간별 변동 요인과 이상 패턴을 교차 검증하고, 상반된 가설을 다각도로 점검합니다.
  • Reporter Agent: 의사결정권자가 즉시 검토할 수 있도록 시각화 차트, 근거 테이블, 리스크 요약으로 정리합니다.

4. 검토 · 승인 후 SyncVerse 실행 연계 (Human-in-the-Loop)

분석 결과가 실제 운영 개선으로 이어지려면 안전한 승인 절차가 필수입니다. SyncInsight는 UI를 SyncVerse 통합 관제 콘솔(/analytics/*)과 자연스럽게 연동해, 경영진과 담당자가 제안된 개선 액션(예: 프로모션 기획전 준비, 운영 임계치 조정, 리스크 점검 티켓 생성)을 검토하고 명시적으로 승인한 경우에만 하위 실행 에이전트로 작업을 전달합니다.

사내 폐쇄망에서도 안전한 일상 언어 데이터 조회를 확인해 보세요 NL2SQL 탐색기와 멀티 에이전트 분석 리포트 화면을 SyncInsight 공식 페이지에서 살펴볼 수 있습니다.
