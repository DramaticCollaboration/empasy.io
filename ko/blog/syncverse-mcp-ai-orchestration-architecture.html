흩어진 업무 도구를 하나로 연결하는 협업·승인 관리: SyncVerse 운영 가이드

경영진 · 현업 담당자를 위한 3줄 요약
  • 기존 문제요청은 메신저에, 점검 결과는 엑셀에, 승인 이력은 메일에 흩어져 있어 진행 상황 파악과 감사 대응이 어렵습니다.
  • 해결 방식요구사항 정리(Spec Studio)부터 작업 검토, 품질 점검 결과, 다자간 단계별 승인 이력을 하나의 관제 화면에 순서대로 묶어 관리합니다.
  • 기대 효과부서 간 소통 누락을 줄이고 누가 무엇을 검토·승인·반영했는지 투명하게 추적할 수 있습니다.

기업 현장에서 개발, 테스트, 콘텐츠 발행, 보안 점검을 지원하는 AI 도구가 늘어나고 있지만, 각 도구의 작업 맥락과 승인 이력이 제각각 흩어져 있으면 결국 담당자가 메신저와 엑셀을 오가며 수동으로 취합해야 합니다. 특히 코드 변경이나 운영 설정 반영처럼 영향 범위가 큰 작업은 누가 어떤 근거로 승인했는지를 남기는 거버넌스가 필수입니다.

엠파시의 중앙 오케스트레이션 플랫폼 SyncVerse는 표준 MCP(Model Context Protocol) 기반의 A2A 협업, 5-Step Spec Studio, 15대 코딩 엔진 동적 라우팅(SyncSDK), 그리고 다자간 승인 결재선(Multi-Party HITL)을 하나의 관제 콘솔에 통합했습니다.

1. MCP 기반 A2A 오케스트레이션 토폴로지

SyncVerse는 사용자의 자연어 요구를 해석한 뒤 A2A 보안 핸드셰이크를 거쳐 각 도메인 전문 에이전트에게 작업을 위임하고, 실제 DB 처리 결과와 검증 리포트를 종합 브리핑으로 정리합니다.

도메인별 에이전트가 각자 실제 데이터베이스와 검증된 MCP 도구를 사용해 작업하므로, 원격 서비스 장애가 발생하더라도 가짜 정상 응답을 숨기지 않고 정확한 진단과 조치 가이드를 투명하게 표시합니다.

2. 5-Step Spec Studio 및 개발자 협업(Co-Dev) 파이프라인

소스코드 수정이 필요한 기능 개발은 즉흥적인 프롬프트 실행 대신, 5단계 구조화 워크플로우를 거쳐 안전하게 진행됩니다.

  1. Step 1 — 요구사항 AC 구조화 & 영향도 탐색: 자연어 요구를 수용 기준(Acceptance Criteria)으로 정리하고, 4단계 코드 그래프 탐색으로 수정 대상 범위를 파악합니다.
  2. Step 2 — 상세 기능 · 화면 명세 검토: 기능 명세와 화면 와이어프레임을 도출하고, 미결사항 결정 대기열(Decision Queue)에서 담당자가 방향을 확정합니다.
  3. Step 3 — 기술 스펙 & API 커버리지 게이트: DDL 스키마, REST API 계약, 집중 수정 파일 목록(focusFiles)을 검증해 누락을 사전에 방지합니다.
  4. Step 4 — SyncSDK 슬라이스 구현 & 4-Cycle 검증: CodingAgentRoutingProxy가 활성화된 코딩 엔진(15종 중 런타임 핫스왑 가능)으로 작업 브랜치(feat/*)와 Pull Request를 생성하고 빌드·테스트 자가 점검을 수행합니다.
  5. Step 5 — 사내 개발자 Co-Dev · Living Spec 역동기화 & SI 산출물: 사내 개발자가 브랜치를 로컬에서 검증·보완하면 변경 사항을 명세서에 역동기화(reverse-sync)하고, 프로그램 사양서·화면 설계서·테이블 명세서·테스트 시나리오 등 SI 납품 산출물을 함께 생성합니다.

3. 엔터프라이즈 운영을 위한 3대 거버넌스 장치

  • 다자간 순차 승인 결재선(Multi-Party HITL): 코드 변이, DB 스키마 변경, 운영 배포 같은 고위험 작업은 개발 -> QA -> 보안 -> 관리자 단계별 승인과 부서별 접근 권한(sys_depart_agent_permission) 정책을 통과해야 실행됩니다.
  • 3단계 하네스 엔지니어링(syncverse_harness_registry): 컨텍스트 주입(Stage 1), 아키텍처·보안 제약 검증(Stage 2), 드리프트·복잡도 억제(Stage 3) 정책을 DB로 관리해 일관된 코드 품질을 유지합니다.
  • 엔터프라이즈 협업 및 KMS 통합: 실시간 스펙 동시 편집 분산 락(Redis Lock), Jira 양방향 일감 연동, Slack/Teams 알림 웹훅, KMS 키 회전 및 만료 워크스페이스 자동 정리를 기본 제공합니다.
