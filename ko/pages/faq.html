자주 묻는 질문

엠파시의 자율형 AI 에이전트에 대해 가장 많이 주시는 질문들을 모았습니다.

자율형 AI 에이전트와 기존 자동화 도구(RPA)의 차이는 무엇인가요?
기존 RPA는 사전에 정해진 룰과 스크립트 기반으로 동작하여 작은 UI 변경이나 시스템 업데이트에도 쉽게 오류가 발생합니다. 반면, 엠파시의 자율형 AI 에이전트는 Vision-LLM을 통해 사람처럼 화면의 요소를 시각적으로 인지하고 의미를 파악하므로, UI 구조가 완전히 변경되어도 스스로 대처하고 복구(Self-Healing)하는 능력을 갖추고 있습니다.
SyncEta를 활용한 웹 UI 테스트 자동화는 동적 변화에 어떻게 대응하나요?
SyncEta는 전통적인 CSS 선택자(Selector)나 XPath에 의존하지 않습니다. 비전 모델(Vision Model)이 화면 전체를 스캔하여 '로그인 버튼'이나 '장바구니 아이콘'을 인간과 동일한 방식으로 식별합니다. 따라서 개발팀이 DOM 구조를 변경하거나 A/B 테스트를 진행하더라도 테스트 스크립트 수정 없이 안정적인 QA 환경을 보장합니다.
레거시 시스템을 클라우드로 전환할 때 SyncBoot가 어떻게 도움을 주나요?
SyncBoot는 수십 년간 누적된 모놀리식 아키텍처의 의존성을 분석하고, 이를 독립적인 마이크로서비스(MSA) 형태로 분리하는 설계 및 초기 코드 스캐폴딩 작업을 자동화합니다. Saga 패턴 기반의 분산 트랜잭션 처리까지 AI가 제안하여, 마이그레이션에 소요되는 인력과 시간을 80% 이상 획기적으로 단축시킵니다.
솔루션 도입에 소요되는 기간은 어느 정도인가요?
도입할 에이전트 종류와 기업의 기존 인프라 환경에 따라 다르나, 일반적으로 PoC(개념 증명) 환경 구성에는 1~2주, 전체 시스템 연동 및 실제 운영 적용까지는 1개월 내외가 소요됩니다. 모든 과정은 엠파시의 전담 엔지니어 팀이 밀착 지원합니다.
제품에 대한 상세한 개발자 문서나 API 명세는 어디서 볼 수 있나요?
엠파시의 모든 솔루션 연동 가이드 및 API 명세, 기술 문서는 공식 문서 센터인 docs.empasy.io에서 확인하실 수 있습니다. 또한 오픈소스 기여 및 플러그인은 공식 GitHub(DramaticCollaboration)를 통해 제공됩니다.
