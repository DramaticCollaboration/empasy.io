Support & FAQ

자주 묻는 질문

업무 자동화 도입 검토 시 가장 궁금해하시는 효과, 안전장치, 보안, 도입 절차를 모았습니다.

도입 효과
기존 RPA나 매크로 자동화처럼 화면이 조금만 바뀌어도 멈추는 문제가 해결되나요?
기존 RPA는 사전에 지정된 태그나 좌표에 의존하므로 작은 화면 개편에도 테스트가 멈춰 유지보수 부담이 컸습니다. 엠파시의 AI는 화면의 글자와 배치를 함께 읽고 판단하여 버튼이나 메뉴 위치가 바뀌어도 사람처럼 대상을 스스로 찾아 작업을 끝까지 완료합니다.
적용 범위
우리 회사 시스템에서 어떤 운영 업무부터 바로 자동화할 수 있나요?
업데이트마다 반복되는 웹·앱 기능 테스트, 외부 사이트 데이터의 정기 수집 및 정리, 다국어 홈페이지 콘텐츠 등록·번역, 여러 시스템의 운영 기록 분석 및 일일 보고서 작성 등 사람이 수작업으로 반복하던 핵심 업무에 바로 적용할 수 있습니다.
업무 협업
기획, 개발, 테스트, 운영처럼 여러 부서가 얽힌 복합 업무도 자동화가 가능한가요?
네. 엠파시는 단일 작업 자동화에 그치지 않고, 웹 제작(SyncCMS), 백엔드 개발(SyncBoot), 자동 테스트(SyncEta), 데이터 분석(SyncInsight) 등 각 업무를 맡은 AI들이 서로 데이터를 자동으로 주고받으며 부서 간 연결된 업무를 매끄럽게 처리합니다.
사용 편의
비개발자(운영자/기획자)도 코드 없이 직접 업무 자동화 규칙이나 콘텐츠를 관리할 수 있나요?
네. 복잡한 코딩 없이도 직관적인 관리자 화면과 일상적인 대화 입력을 통해 업무 규칙을 설정하고 웹 화면을 편집할 수 있습니다. 변경 사항은 실시간 미리보기로 바로 확인할 수 있습니다.
자동 테스트 (QA)
업데이트마다 반복되는 기능 점검과 화면 깨짐 확인을 자동화할 수 있나요?
네. SyncEta를 통해 마우스 조작 녹화나 기존 엑셀 테스트 문서만으로 자동 테스트를 만들고 실행할 수 있습니다. 디자인이 바뀌어도 화면이 바뀌어도 버튼을 스스로 찾는 기능이 작동하여 테스트 수정 시간을 80% 이상 줄여줍니다.
자동 개발
오래된 사내 시스템을 최신 환경으로 개편할 때 개발 기간을 줄일 수 있나요?
네. SyncBoot가 기존 시스템의 데이터 구조를 분석하고 서버 코드와 관리자 화면을 자동으로 생성해주어, 시스템 개편에 걸리는 시간과 비용을 크게 줄여줍니다.
데이터 수집·정리
대상 사이트 화면이 수시로 바뀌는 외부 웹 데이터 수집도 중단 없이 유지되나요?
네. SyncCrawl이 웹사이트의 화면 구조 변경을 감지해 수집 위치를 스스로 보정합니다. 접속 차단 방지와 대량 분산 처리를 통해 365일 끊김 없이 데이터를 수집하고 깔끔하게 정리합니다.
데이터 분석·전략
단순 통계 차트를 넘어 AI가 운영 데이터의 원인 분석과 실행 방안까지 제시해주나요?
네. 기존 대시보드가 과거 숫자를 보여주는 데 그친다면, SyncInsight는 사내외 데이터를 함께 분석해 변화의 원인을 파악하고, 관리자가 승인해 바로 실행할 수 있는 대응 방안을 보고서로 제안합니다.
비용 절감 및 예산 관리
사내 AI 도입 시 늘어나는 AI 모델 사용 요금은 어떻게 줄이나요?
SyncLLM이 질문의 난이도에 맞춰 알맞은 AI 모델을 자동으로 연결하고, 중복 질문 재사용으로 비용 절감 및 일일 예산 한도 설정을 적용하여 AI 운영 비용을 40~60% 아껴줍니다.
관리자 승인
AI가 잘못 판단하여 데이터를 임의로 바꾸거나 운영 사고를 낼 위험은 어떻게 막나요?
AI가 시스템을 임의로 변경하지 못하도록 관리자 단계별 승인을 거칩니다. AI는 먼저 설계서와 변경 계획서를 작성해 제출하며, 담당 관리자가 검토하고 승인한 작업만 실제로 반영됩니다.
비상 정지
이상 징후나 위급 상황 발생 시 전체 자동화를 즉시 멈출 수 있나요?
네. 관리 화면의 비상 정지 스위치를 누르면 단 1초 만에 모든 AI의 수정 권한을 회수하고 시스템을 안전한 읽기 전용 모드로 보호하여 추가 사고를 막습니다.
사내 서버 설치
보안 규정이 엄격한 사내 폐쇄망이나 망분리 환경에서도 외부 유출 없이 쓸 수 있나요?
네. 외부 인터넷과 완전히 분리된 사내 전용 서버 및 폐쇄망 환경에 독립적으로 설치할 수 있습니다. 사내 설치형 AI 모델과 연결하여 기업의 핵심 데이터와 코드가 외부로 나가지 않습니다.
개인정보 보호
운영 중 고객 개인정보나 결제 정보 등 민감한 데이터가 외부 AI에 유출되지 않나요?
개인정보 자동 가림 처리 기능이 주민등록번호, 계좌번호, 연락처 등을 실시간으로 찾아내 안전하게 가려줍니다. 또한 기업 고객의 어떠한 운영 데이터도 외부 AI 학습에 활용되지 않습니다.
사전 검증 (PoC)
본격 도입 전에 우리 회사 업무 환경에서 효과가 있는지 먼저 검증(PoC)해볼 수 있나요?
네. 실제 도입 전 고객사의 대표 업무 1~2개를 선정하여 약 1~2주간 효과를 직접 확인하는 사전 검증(PoC) 프로그램을 운영합니다. 전담 엔지니어가 실제 업무 시간 절감 효과를 수치로 측정해 드립니다.
도입 방식 & 효과
도입 비용은 어떤 기준으로 책정되며, 얼마나 비용을 절감할 수 있나요?
클라우드 구독형과 사내 서버 구축형 중 선택할 수 있으며, 필요한 솔루션만 골라 도입할 수도 있습니다. 도입 기업들은 반복적인 점검과 수작업 시간을 평균 60~80% 줄이고 있습니다.
도입 상담
도입 상담이나 기술 지원은 어떻게 받을 수 있나요?
도입 문의 페이지를 통해 문의를 남겨주시면 영업일 기준 24시간 이내에 담당 아키텍트가 시스템 환경을 검토한 뒤 맞춤형 도입 방안을 안내해 드립니다.
