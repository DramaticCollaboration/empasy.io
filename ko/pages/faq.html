Support & FAQ

자주 묻는 질문

엠파시의 AI 자율 운영 생태계와 엔터프라이즈 도입에 관해 자주 묻는 질문을 모았습니다.

핵심 아키텍처
자율형 AI 에이전트와 기존 자동화 도구(RPA)의 차이는 무엇인가요?
기존 RPA는 사전에 정해진 규칙과 정적 셀렉터(Selector) 스크립트 기반으로 동작하여 작은 UI 변경이나 시스템 업데이트에도 쉽게 오류가 발생합니다. 반면 엠파시의 자율형 AI 에이전트는 Vision-LLM을 통해 사람처럼 화면 요소를 시각적으로 인지하고 의미를 파악하므로, UI 구조가 완전히 변경되어도 스스로 대처하고 복구(Self-Healing)하는 능력을 갖추고 있습니다.
핵심 아키텍처
SyncVerse 중앙 관제탑과 에이전트 간(A2A) 협업은 어떻게 동작하나요?
SyncVerse는 표준 Model Context Protocol(MCP)과 Agent-to-Agent(A2A) 통신 프로토콜을 기반으로 모든 하위 에이전트를 실시간 조율합니다. 기획(SyncCMS), 개발/스캐폴딩(SyncBoot), 데이터 수집(SyncCrawl), 검증(SyncEta), 의사결정 분석(SyncInsight), LLM 거버넌스(SyncLLM)가 하나의 유기적인 생태계로 작업 지시와 피드백을 주고받습니다.
핵심 아키텍처
Spec-First 거버넌스와 Human-in-the-Loop(HITL) 원칙이란 무엇인가요?
AI 에이전트의 환각(Hallucination)이나 비인가 코드 생성을 방지하기 위해 엠파시는 'Spec-First 거버넌스'를 적용합니다. AI는 먼저 기획 명세서와 작업 명세를 선행 작성하고, 관리자의 디지털 서명 승인(Human-in-the-Loop)을 획득한 후에만 실제 코드 브랜치 생성 및 빌드를 실행합니다.
핵심 아키텍처
비상 상황 시 동작하는 Emergency Kill-Switch 기능은 어떤 원리인가요?
이상 트래픽, 비정상 토큰 급증, 모델 이상 징후 또는 보안 위협 감지 시 단 한 번의 조작이나 자동 임계치 감지로 전체 에이전트의 쓰기 권한을 즉시 박탈하고 시스템을 읽기 전용 격리(ReadOnly Lockdown)로 전환하여 기업 자산과 데이터를 안전하게 보호합니다.
SyncEta (QA)
SyncEta를 활용한 웹 UI 테스트 자동화는 동적 변화에 어떻게 대응하나요?
SyncEta는 전통적인 CSS 선택자(Selector)나 XPath에 의존하지 않습니다. 비전 모델(Vision Model)이 화면 전체를 스캔하여 '로그인 버튼'이나 '장바구니 아이콘'을 인간과 동일한 방식으로 식별합니다. 따라서 개발팀이 DOM 구조를 변경하거나 A/B 테스트를 진행하더라도 테스트 스크립트 수정 없이 안정적인 QA 환경을 보장합니다.
SyncEta (QA)
SyncEta는 기존 Playwright, Selenium, Cypress 테스트 환경과 어떻게 통합되나요?
기존에 구축된 Playwright나 Selenium 테스트 파이프라인 상단에 드롭인(Drop-in) 래퍼 형태로 구동됩니다. 기존 테스트 코드를 전면 재작성할 필요 없이 비전 기반 자가 치유 레이어와 크로스 브라우저 회귀 테스트 기능만 즉시 확장할 수 있습니다.
SyncBoot (개발)
레거시 시스템을 클라우드로 전환할 때 SyncBoot가 어떻게 도움을 주나요?
SyncBoot는 수십 년간 누적된 모놀리식 아키텍처의 의존성을 분석하고, 이를 독립적인 마이크로서비스(MSA) 형태로 분리하는 설계 및 초기 코드 스캐폴딩 작업을 자동화합니다. Saga 패턴 기반의 분산 트랜잭션 처리까지 AI가 제안하여, 마이그레이션에 소요되는 인력과 시간을 80% 이상 획기적으로 단축시킵니다.
SyncCMS (콘텐츠)
SyncCMS는 비개발자(기획자/마케터)도 코드 없이 복잡한 콘텐츠와 화면을 관리할 수 있나요?
네, 기획자가 자연어 프롬프트와 실시간 라이브 프리뷰 화면을 통해 컴포넌트를 배치하고 콘텐츠를 편집할 수 있습니다. 원문 수정 시 연결된 다국어(한국어, 영어, 일본어) 리소스 번역이 백그라운드에서 자동 동기화되어 글로벌 배포 주기를 단축합니다.
SyncCrawl (수집)
SyncCrawl은 웹사이트 구조 변경이나 안티봇 환경에서 어떻게 중단 없는 데이터 수집을 보장하나요?
시각적 렌더링 분석 엔진을 탑재하여 타깃 사이트의 마크업 구조가 변경되어도 시각적 레이아웃 기반으로 수집 룰을 실시간 자동 보정합니다. 또한 대규모 분산 워커 노드 스케일링과 RAG 표준 벡터 스토리지(OpenSearch, Pinecone, Milvus 등) 연동을 기본 지원합니다.
SyncInsight (인텔리전스)
기존 대시보드(BI) 솔루션과 SyncInsight의 차이점은 무엇인가요?
기존 BI는 과거 통계를 차트로 시각화하는 데 중점을 두지만, SyncInsight는 내외부 데이터를 결합해 원인을 분석하는 딥 리서치(Deep Research)를 수행하고, 에이전트 간 검토를 거쳐 관리자 승인 기반으로 실행 가능한 액션 플랜을 도출합니다.
SyncLLM (거버넌스)
SyncLLM은 멀티 LLM 라우팅과 기업 FinOps(비용 절감)를 어떻게 실현하나요?
질의의 복잡도와 의도를 실시간 분석하여 단순 질의는 가벼운 SLM(Small Language Model)으로, 복잡한 추론은 고성능 LLM으로 지능형 라우팅합니다. 부서별/프로젝트별 일일 토큰 예산 Cap 설정, 실시간 PII 마스킹, 시맨틱 캐싱을 통해 LLM 운영 비용을 최대 60% 절감합니다.
보안 및 배포
금융, 공공, 대기업을 위한 온프레미스(On-Premise) 및 에어갭(Air-Gapped) 폐쇄망 배포가 가능한가요?
네. 엠파시의 모든 솔루션은 인터넷 접속이 완전히 차단된 사내 폐쇄망(Air-Gapped) 및 사내 VPC 환경에 컨테이너 기반으로 100% 격리 배포될 수 있습니다. vLLM, Ollama 등 로컬 오픈소스 LLM 런타임과 결합하여 기업의 핵심 기밀과 소스코드가 외부망으로 1바이트도 유출되지 않습니다.
보안 및 배포
기업 내 민감 데이터(주민등록번호, 금융정보 등)와 개인정보 보호(PII)는 어떻게 처리되나요?
내장된 개인정보 보호 필터가 주민번호, 연락처, 카드번호, 계좌번호 등을 사전에 감지하여 실시간 마스킹(가명화) 처리하며, 기업 요구사항에 따라 사내 구축형 로컬 LLM과의 연동을 지원하여 완벽한 데이터 주권을 보장합니다.
엔터프라이즈 도입
솔루션 도입에 소요되는 기간과 PoC(개념 증명) 절차는 어떻게 되나요?
도입할 에이전트 종류와 기업의 기존 인프라 환경에 따라 다르나, 일반적으로 PoC 환경 구성에는 1~2주, 전체 시스템 연동 및 실제 운영 적용까지는 1개월 내외가 소요됩니다. 모든 과정은 엠파시의 전담 엔지니어 팀이 밀착 지원합니다.
라이선스
라이선스 정책 및 과금 모델은 어떻게 구성되어 있나요?
기업의 규모와 배포 방식에 맞춰 클라우드 SaaS 구독형 및 온프레미스 영구/연간 엔터프라이즈 라이선스를 지원합니다. 노드 수 및 에이전트 모듈별 유연한 패키징이 가능하며, 세부 견적은 도입 규모 진단 상담을 통해 맞춤 제공됩니다.
지원 및 문서
제품에 대한 상세한 개발자 문서나 API 명세는 어디서 볼 수 있나요?
엠파시의 모든 솔루션 연동 가이드 및 API 명세, 기술 문서는 공식 문서 센터인 doc.empasy.com에서 확인하실 수 있습니다. 또한 오픈소스 기여 및 플러그인은 공식 GitHub(DramaticCollaboration)를 통해 제공됩니다.
