Core Architecture & Safety

Spec-First 자율 엔지니어링 & 안전 가드레일

무분별한 코드 생성을 방지하고, 명세서 선행 승인과 자가 복구를 통해 시스템 신뢰성을 보장합니다.

3대 작업 처리 트랙 (Triple Execution Tracks)

Track 1 • No-Code Data

콘텐츠 & 도메인 데이터 자율 발행

블로그, 카탈로그, 시스템 설정 등 코드 수정이 불필요한 작업은 전문 에이전트(SyncCMS, SyncShop)가 자체 DB에 직접 반영 및 동기화합니다.

Track 2 • Direct Patch

AST 분석 & 자가 치유 패치 PR

단일 컴포넌트나 UI 버그는 SyncSDK가 구문 트리(AST)를 분석해 자가 치유 패치를 생성하고 자동 E2E 검증 후 GitHub PR을 오픈합니다.

Track 3 • Spec-First HITL

기획/설계 명세서 선행 검토

대규모 신규 기능 시 코드를 바로 작성하지 않고, 기획서(PRD) → API/DB 명세서 → 화면 명세서를 생성하여 관리자 승인 후 오차 없이 일괄 구현합니다.

Vision-LLM Engine

DOM 구조, 클래스명이 변경되어도 화면 레이아웃과 텍스트 문맥을 분석하여 대상 UI 요소를 재식별하고 테스트 경로를 자가 복구(Self-Healing)합니다.

FinOps & PII Guardrail

SyncLLM을 통해 실시간 개인정보(주민번호/카드번호)를 마스킹하고, Redis 시맨틱 캐시와 일일 예산 캡(Cap)으로 토큰 비용 폭증을 방어합니다.

Saga Pattern MSA Control

마이크로서비스 환경에서 단계별 장애 발생 시, 사전 정의된 보상 트랜잭션을 트리거하여 분산 데이터의 정합성을 일관되게 유지합니다.

Emergency Kill-Switch

이상 징후 발생 시 단 한 번의 조작으로 모든 에이전트의 쓰기 권한을 박탈하고 시스템을 읽기 전용 격리(ReadOnly Lockdown)로 전환합니다.
