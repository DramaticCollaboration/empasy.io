Frequently Asked Questions (FAQ)

Is SyncEta desktop app free to download and run?

Yes, you can download installers for Windows and macOS directly from empasy.io to test local and staging web applications immediately.

How does SyncEta selector self-healing work?

When DOM hierarchies or class names change after deployments, SyncEta Vision-LLM analyzes visual context and component positioning to infer replacement selectors, preventing test pipeline failures.

Can SyncEta be used within corporate private intranets or VPNs?

Yes, SyncEta controls the local Playwright browser runtime directly on your machine, enabling testing on localhost and corporate VPN environments without external cloud exposure.
