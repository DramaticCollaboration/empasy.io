Frequently Asked Questions

Explore answers to common questions about Empasy's autonomous AI ecosystem and enterprise integration.

Core Architecture
What is the difference between autonomous AI agents and traditional automation tools (RPA)?
Traditional RPA operates based on predefined static rules and selector scripts, easily causing failures with minor UI changes or system updates. In contrast, Empasy's autonomous AI agent visually recognizes and understands screen elements like a human through Vision-LLM, enabling it to cope and recover (Self-Healing) on its own even if the UI structure completely changes.
Core Architecture
How does the SyncVerse Central Control Tower and Agent-to-Agent (A2A) collaboration work?
SyncVerse orchestrates all specialized agents in real time based on standard Model Context Protocol (MCP) and Agent-to-Agent (A2A) communication protocols. Planning (SyncCMS), Development/Scaffolding (SyncBoot), Web Extraction (SyncCrawl), Testing (SyncEta), Decision Intelligence (SyncInsight), and LLM Governance (SyncLLM) collaborate seamlessly in a unified ecosystem.
Core Architecture
What are Spec-First Governance and Human-in-the-Loop (HITL) principles?
To eliminate hallucination risks and unauthorized code modifications, Empasy enforces Spec-First Governance. AI agents must first generate verifiable specification documents and test plans, and require cryptographic administrator approval (Human-in-the-Loop) before creating Git branches or executing build pipelines.
Core Architecture
How does the Emergency Kill-Switch function work during critical anomalies?
Upon detecting anomalous traffic, abnormal token surges, model degradation, or unauthorized access, a single administrator action or automated threshold alert instantly revokes write permissions across all agents and locks the system into ReadOnly Lockdown, safeguarding infrastructure and proprietary data.
SyncEta (QA)
How does web UI test automation using SyncEta respond to dynamic changes?
SyncEta does not rely on fragile CSS Selectors or XPath. Its Vision-LLM model scans the entire screen layout to identify elements like login buttons or shopping cart icons just like a human tester. Therefore, even if the development team changes the DOM hierarchy or runs A/B experiments, QA tests execute reliably without manual script revisions.
SyncEta (QA)
How does SyncEta integrate with existing Playwright, Selenium, or Cypress environments?
SyncEta integrates as a drop-in wrapper on top of your existing Playwright or Selenium test pipelines. You do not need to rewrite existing test suites; you can immediately leverage vision-powered self-healing regression testing across both desktop and mobile viewports.
SyncBoot (Development)
How does SyncBoot assist in migrating monolithic legacy systems to cloud-native microservices (MSA)?
SyncBoot deeply analyzes legacy monolithic codebases, data models, and service dependencies to architect decoupled microservice boundaries. It automates Spring Boot entity generation, CRUD APIs, DDL scripts, and even generates Saga pattern distributed compensation transactions, accelerating modernization timelines by over 80%.
SyncCMS (Content)
Can non-developers (planners and marketers) manage complex content without code using SyncCMS?
Yes. SyncCMS provides an intuitive visual interface where non-technical planners can arrange components and edit structured content via natural language prompts and live previews. When content is updated, multilingual translations (Korean, English, Japanese) are automatically synchronized in the background.
SyncCrawl (Extraction)
How does SyncCrawl ensure uninterrupted data extraction amidst anti-bot defenses and layout changes?
Equipped with a visual rendering intelligence engine, SyncCrawl dynamically recalibrates crawling rules based on visual layout cues when target website markup changes. It natively supports distributed worker node autoscaling and standard vector database sinks (OpenSearch, Pinecone, Milvus) for enterprise RAG pipelines.
SyncInsight (Intelligence)
How does SyncInsight differ from traditional BI dashboards, and how does it support decision-making?
While traditional BI simply aggregates past data into charts, SyncInsight autonomously conducts Deep Research by correlating internal metrics with external market signals. Through multi-agent cross-review and simulation, it synthesizes concrete, executable action plans requiring administrator sign-off.
SyncLLM (Governance)
How does SyncLLM achieve multi-LLM intelligent routing and enterprise FinOps cost optimization?
SyncLLM analyzes query complexity and intent in real time, routing simple queries to lightweight SLMs and complex reasoning tasks to high-tier LLMs. With granular token budget caps, real-time PII masking, and semantic caching, it cuts enterprise LLM operational costs by up to 60%.
Security & Deployment
Can the platform be deployed on-premise and in air-gapped secure networks for finance and government?
Yes. All Empasy solutions can be deployed 100% isolated in containerized on-premise environments, private VPCs, and completely air-gapped networks without external internet access. When combined with local open-source LLM runtimes (vLLM, Ollama), not a single byte of proprietary code or confidential data leaves your perimeter.
Security & Deployment
How is sensitive internal data (PII, financial numbers) protected during AI operations?
Built-in data protection filters proactively detect resident registration numbers, phone numbers, payment card numbers, and bank account information, applying real-time pseudonymization and masking before processing, ensuring complete compliance and data sovereignty.
