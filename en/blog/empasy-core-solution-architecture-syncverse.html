SyncSeries aligns Empasy's enterprise software portfolio on a shared engineering stack—Java 25, Spring Boot 4.0, PostgreSQL 18.6 with pgvector, Vue 3 / Nuxt 3, Playwright, and MCP/A2A protocols. Below is a clear architectural breakdown of the 4 core operational areas and 7 modular extensions.

1. SyncETA: Click-Based Automated Screen Checks & Self-Healing QA

Operational Bottleneck

Frequent UI updates break brittle locator-based scripts, turning automated testing into a constant maintenance burden before every release.

Engineering Approach

  • Click Recording to Structured Excel Scenarios: Captures DOM interactions and accessibility trees, converting them into readable Step-Input-Expected Result sheets editable by non-developers.
  • Deterministic Playwright Replay: Executes recurring regression runs without calling external LLM APIs on every pass, keeping ongoing execution cost predictable.
  • Self-Healing Locators & Quality Gates: Invokes contextual DOM analysis only when UI elements shift, alongside load/chaos verification and release quality gates.

2. SyncCMS: Vendor-Independent Multilingual Website Platform

Operational Bottleneck

Operating separate brand and regional sites often forces marketing teams to wait on engineering deployments for routine copy, layout, or localization changes.

Engineering Approach

  • Spring Boot + Nuxt 3 SSR Hybrid Headless: Delivers fast server-rendered pages for SEO alongside clean RESTful APIs for omnichannel reuse.
  • 3-Agent Review Workflow: Coordinates drafting, SEO/accessibility/compliance review, and controlled publishing—always gated by human approval.
  • Single-Console Multi-Site Governance: Manages regional permissions, shared content models, and revision history from one workspace.

3. SyncBoot: Standard Internal Management Core

Operational Bottleneck

Rebuilding sign-in, organization-linked permissions, electronic approvals, and audit trails from scratch on every internal application delays delivery and creates inconsistent security.

Engineering Approach

  • Ready-Made Enterprise Core: Provides organization RBAC (menu and button level), multi-step electronic approvals, data portals, and audit logging out of the box.
  • Database-Driven Dynamic Config & Prompt Hub: Updates operational thresholds (sys_config) and AI prompts (sys_prompt_template) at runtime with ClusterEventBroadcaster multi-instance sync.
  • Reliability & Observability: Includes SagaCoordinator compensation workflows, distributed Trace ID tracking, and Slow SQL diagnostics.

4. SyncVerse: Central Collaboration & Staged Approval Hub

Operational Bottleneck

Even with AI tools in place, scattered chat requests, code diffs, test reports, and email sign-offs make auditability and change control difficult.

Engineering Approach

  • MCP-Based A2A Orchestration: Delegates domain goals securely across connected agents and synthesizes structured operational briefings.
  • 5-Step Spec Studio & 15 Coding Engine Routing: Guides teams from acceptance criteria and API specs to branch/PR creation via SyncSDK and 4-Cycle quality checks.
  • Multi-Party HITL & 3-Stage Harness Governance: Enforces context, constraint, and entropy guardrails plus multi-role sign-off before production rollout.

5. SyncInsight: Private-Network Decision Intelligence

Operational Bottleneck

Siloed ERP records and strict data-residency rules prevent business leaders from using public cloud AI tools directly on sensitive corporate data.

Engineering Approach

  • On-Premise & Air-Gapped Readiness: Runs storage and local LLM runtimes (vLLM, Ollama) inside private corporate infrastructure.
  • Read-Only NL2SQL Firewall & Hybrid RAG: Protects production databases with Apache Calcite and JSqlParser SELECT-only enforcement while indexing unstructured documents via pgvector + BM25 + Knowledge Graph.
  • Structured Analysis to Action: Delivers tables, charts, and cited summaries, handing approved initiatives off to SyncVerse cleanly.

6. Six Additional Modular Extensions on the Same Core

Alongside SyncInsight covered above, organizations can add any of the following six extensions built on the same shared modules (sync-core, sync-module-ai, sync-module-rag, sync-module-nl2sql, sync-module-audit, sync-module-deploy):

  • SyncLLM: Central AI gateway with semantic caching, departmental budgets, PII masking, and multi-provider failover.
  • SyncCrawl: Compliant web-to-RAG collection pipeline with Playwright self-healing selectors and hash-based diffing.
  • SyncShop: Independent 9-service MSA commerce platform with minimum-margin guards and one-click snapshot price rollback.
  • SyncOps: Project profitability pivot analytics, dual billing/cost rates, surety bond tracking, and statutory payment deadline alerts.
  • SyncAPIM: Context-aware lexical threat detection, shadow API discovery, zero-downtime virtual patching, eBPF kernel defense, and response PII masking.
  • SyncWatch: Aggregates global vulnerability feeds (NVD, CISA KEV, KISA, etc.), compiles verified audit/defense packs, and distributes them to SyncVerse and SyncAPIM.
