Engineering organizations adopting AI coding assistants face two recurring challenges: locking workflows to a single vendor makes adapting to model pricing or security rules painful, and rapid code changes cause specification and documentation drift almost immediately.

Empasy addresses both with SyncSDK's 15-engine standard SPI and SyncVerse's 5-Step Spec Studio & Living Spec reverse-sync workflow.

1. ICodingAgentClient SPI & 15-Engine Runtime Hot-Swap

sync-sdk-common standardizes execution behind ICodingAgentClient and the CodingAgentType registry across four execution modes:

  • SDK Native (1): ANTIGRAVITY (Google Antigravity SDK v2.0 multi-agent harness)
  • CLI Subprocess (11): CLAUDE_CODE, GITHUB_COPILOT, CODEX_CLI, GEMINI_CLI, CURSOR_CLI, CONTINUE, AIDER, GOOSE, MINI_SWE, CLINE, KIRO
  • Isolated Docker Container (2): OPENHANDS, OPENSWE
  • REST API (1): EIGENT

CodingAgentRoutingProxy switches active engines at runtime with zero restarts, while per-engine default models resolve dynamically from PostgreSQL via SystemConfigHolder (sync.sdk.agent.default-model.<code_lower>).

2. 5-Step Spec Studio & Human Co-Dev Lifecycle

STEP 01
Acceptance Criteria & Code Graph Scope
Structures plain-language requests into AC items and traces impact via 4-stage dependency analysis
STEP 02
Functional/Screen Specs & Decision Queue
Produces screen wireframes and tracks L1/L2/L3 open decisions for explicit human resolution
STEP 03
Technical Spec & API Coverage Gate
Validates DDL schemas, REST contracts, and target focusFiles before writing code
STEP 04
SyncSDK Sliced Coding & 4-Cycle Checks
Routes work to the active engine (1 of 15), opens feat/* PRs, and verifies build & tests
STEP 05
Co-Dev Review, Reverse-Sync & Deliverables
Engineers verify locally, reverse-sync manual edits to Living Specs, and export 4 SI deliverables

3. Living Spec Reverse-Sync & Automated SI Deliverables

  • Living Spec Reverse-Sync (LivingSpecReverseSyncService): Whenever an internal engineer refines edge cases directly in the branch, reverse-sync parses the actual Git diff and updates functional and API specs automatically.
  • 4 Standard Delivery Artifacts (SpecDeliverableAndGovernanceSupport): Generates Program Specifications (HTML), Screen Design Docs (HTML), Table Definitions (CSV/XLSX), and Unit Test Scenarios (CSV/XLSX) directly from verified specs.

4. Vendor Independence With Enterprise Accountability

Pairing interchangeable coding engines with explicit specification gates, local human review, and synchronized deliverables lets engineering leaders adopt advancing AI capabilities without sacrificing governance or audit readiness.
