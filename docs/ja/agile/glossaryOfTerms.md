## 📚 スクラムバン用語辞典

| カテゴリ | 韓国語 | 英語 | 略語 | 説明 |
| --------- | ------------------ | ----------------------- | ---- | ------------------------------------------------------------------------------- |
| 基本概念 | スクラムバン(스크럼반) | Scrumban | - | スクラム(Scrum)とカンバン(Kanban)のメリットを組み合わせたアジャイルプロジェクト管理フレームワーク |
| 基本概念 | スクラム(스크럼) | Scrum | - | 反復(iteration)とスプリント中心のアジャイル開発方法論 |
| 基本概念 | カンバン(칸반) | Kanban | - | ワークフローを視覚化し、進行中の作業(WIP)を制限する方式のプロジェクト管理手法 |
| 基本概念 | アジャイル(애자일) | Agile | - | 柔軟かつ反復的な方式で製品を開発する哲学および方法論の集合 |
| 作業単位 | 作業項目(작업 항목) | Work Item | - | チームが遂行すべき具体的な作業の単位 |
| 作業単位 | ユーザーストーリー(사용자 스토리) | User Story | - | ユーザーの要件を簡単なストーリー形式で表現した作業単位 |
| 作業単位 | タスク(태스크) | Task | - | ユーザーストーリーや作業をより小さな単位に分けた詳細な実行項目 |
| ボード構成 | バックログ(백로그) | Backlog | - | まだ着手していないすべての作業項目のリスト |
| ボード構成 | 準備完了(준비됨) | Ready | - | 着手する準備が完了した作業項目の状態 |
| ボード構成 | 進行中(진행 중) | In Progress | - | 現在作業が進行している状態 |
| ボード構成 | レビュー中(검토 중) | Review | - | 完了した作業が品質レビューを待っている状態 |
| ボード構成 | 完了(완료) | Done | - | すべてのレビューを通過し、デプロイの準備ができた状態 |
| 運用ルール | 進行中作業の制限(진행 중 작업 제한) | Work In Progress Limit | WIP | 同時に進行できる作業項目の最大数 |
| 運用ルール | リードタイム(리드 타임) | Lead Time | - | 作業依頼が発生した時点から完了するまでにかかった全体の時間 |
| 運用ルール | サイクルタイム(사이클 타임) | Cycle Time | - | 作業に着手した時点から完了するまでにかかった時間 |
| 運用ルール | フロー効率(플로우 효율성) | Flow Efficiency | - | 作業進行時間に対する実際に作業に消費された時間の割合 |
| イベント | デイリースタンドアップ(데일리 스탠드업) | Daily Stand-up | - | 毎日短時間で行われるチームの進捗状況共有ミーティング |
| イベント | スプリント計画会議(스프린트 계획 회의) | Sprint Planning Meeting | - | 次のスプリントで実行する作業を計画する会議 |
| イベント | レビュー会議(리뷰 회의) | Review Meeting | - | 完了した作業をレビューし、フィードバックを受ける会議 |
| イベント | 振り返り(회고) | Retrospective | - | チームが一定の周期で行うプロセス改善会議 |
| 測定指標 | バーンダウンチャート(번다운 차트) | Burndown Chart | - | 残りの作業量を時間経過に沿って視覚化したチャート |
| 測定指標 | 累積フロー図(누적 흐름도) | Cumulative Flow Diagram | CFD | 作業状態別の累積項目の変化を視覚化し、ボトルネックを把握するチャート |
