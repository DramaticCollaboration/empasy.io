スクラムバン段階別アクティビティガイド ​

段階主なアクティビティ詳細説明
1. Backlog- 新規アイデア/リクエストの収集
- バックログアイテムの記録
- サービス・クラスの指定		すべての作業の出発点。
ビジネスリクエスト、バグ、技術的負債などを Product Owner やチームが記録。
各カードに 優先順位 と 作業タイプ(緊急・期限固定・標準・無形) を指定。
この段階ではまだ開始準備ができていない状態。
2. Ready- Definition of Ready(DoR)の確認
- 作業の分割(必要な場合)
- 担当者未指定		作業がすぐに開始できるように詳細が準備された状態。
DoRの基準(要件の明確化、デザイン/リソースの確保、テスト条件の定義など)を満たす必要があります。
通常、補充(Replenishment)ミーティングでBacklogからReadyに移動。
3. Doing / In Progress- 作業の開始(Pull)
- 進行状況のアップデート
- ブロッカーの表示		チームメンバーがWIP制限内でReadyからPullして開始。
作業中に発生した ボトルネック/ブロッカー はボード上に視覚的に表示(赤いラベル、アイコンなど)。
デイリースタンドアップでステータスを共有。
4. Review (Code Review / Peer Review)- コードレビュー/ドキュメントレビューの実行
- フィードバックの反映		開発が終わった作業はレビューカラムに移動。
指定されたレビュアーがコードの品質、標準への準拠を確認。
レビューフィードバックがあればDoingに戻るか、修正後に再度Review段階へ。
5. Testing / QA- 機能テスト
- バグレポートの作成と修正		QAまたはチームメンバーがテストを実行。
自動テスト + 手動テストの併用が可能。
バグがあれば該当のカードに記録し、修正後に再検証。
6. Done- Definition of Done(DoD)の満たし確認
- ドキュメント作成/リリースノートの更新
- デプロイ完了		すべての品質基準を満たし、デプロイまで完了した状態。
リリースノート、ユーザーマニュアルなどのドキュメント作成を含む。
カードに完了日を記録(サイクルタイム分析に活用)。

各段階のアクティビティフローの視覚化 ​

[Backlog]
  ↓ (補充ミーティング)
[Ready]
  ↓ (Pull & WIPチェック)
[Doing]
  ↓ (開発完了)
[Review]
  ↓ (レビュー承認)
[Testing]
  ↓ (品質検証完了)
[Done]

段階別の運用ヒント ​

1. Backlog ​

  • 優先順位基準の明確化: 緊急度、価値、期限、リスクに基づく
  • カードサイズの標準化: 大きすぎる場合はReadyの前に分割
  • 定期的な整理: 古い/不要なカードは破棄

2. Ready ​

  • 作業着手可能条件(DoR)チェックリスト例
    • 要件が明確である
    • デザイン/データ/リソースが確保されている
    • テスト条件が定義されている
    • 予想作業時間/範囲が確認されている

3. Doing ​

  • Stop Starting, Start Finishing (始めることをやめ、終えることを始めよ) ルールを維持
  • ボトルネック発生時は即座に解決を議論
  • マルチタスクの最小化

4. Review ​

  • コードレビュー基準の定義 (例：コードスタイル、パフォーマンス、セキュリティ、テストの有無)
  • レビュー待ち時間を減らすための通知システムの活用

5. Testing ​

  • 自動テストと手動テストの併用
  • バグ発生時は同じカードで修正後に再検証
  • テスト失敗時はWIP超過の例外を許可可能

6. Done ​

  • 完了後、カードに サイクルタイムを記録
  • リリース振り返り時に完了したカードをレビュー
  • データ分析用のタグ(バグ、新機能など)を付与

段階別の主要指標 ​

段階核心指標活用の目的
Backlog → Readyリードタイム(リクエスト〜準備完了)準備遅延の原因把握
Ready → DoingPull頻度チームの処理能力の把握
Doing平均WIP、ブロッカーの割合ボトルネック管理
Reviewレビュー待ち時間品質とスピードのバランス
Testing欠陥率、再作業率QAの効率性
Doneサイクルタイム、スループット予測可能性の改善

このように整理することで、スクラムバンを導入したチームが各段階で何をすべきかが明確になり、 メトリクスに基づいた改善活動も並行して行うことができます。
