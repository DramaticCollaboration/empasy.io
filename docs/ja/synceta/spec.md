# SyncETA ハードウェアおよびソフトウェア詳細仕様書

本文書では、SyncETA回帰テスト自動化ソリューションのハードウェアおよびソフトウェア仕様を詳細に記述します。
ユーザーのWebブラウザ動作レコーディング、テスト実行、結果管理、およびその他の付随的な機能について説明します。

## 1. システム展開および運用環境

- **展開形態**: SyncETAはDockerベースのインストール型(On-premise)またはクラウドSaaS(Software as a Service)形式でデプロイできます。
- **セキュリティ要件**: セキュリティ要件に応じて、LLMモデルをオンプレミスで実行できるようにサポートします。
- **テスト環境**: 開発サーバーではなく本番サーバーを対象にシナリオの録画および実行を行い、実際の環境でのテストをサポートします。

## 2. システム構成要素および詳細機能

SyncETAは大きく次のようなモジュールで構成されます。

### 2.1 SyncETA Recorder (ユーザー行動録画モジュール)

**技術**: Selenium技術を使用します。Seleniumベースの強力で使いやすいフレームワークを活用して、テストの作成および保守を簡素化し、Webテストプロセスを最適化します。

**機能**:

- ユーザーの実際のブラウザ動作(クリック、入力、スクロール、ページ移動、タブ情報など)をリアルタイムにキャプチャし録画します。
- 録画時にURL、XPath、クラス、ID、DOM情報などの詳細なイベントおよびDOM情報を記録します。
- 録画された動作は、テスト目的に合ったシナリオとして自動生成され、JSON/YAMLベースのフォーマットで保存されます。
- 複数のユーザーが同時に相互作用するシナリオの録画をサポートします。

**ユーザーインターフェース**:

- 録画するWeb URLを入力し、自由なWebブラウザの選択およびサイズ設定ができる便利な画面を提供します。
- 多様なユーザーイベントを収集し、直感的なGUIおよびキーワードベースの非コード方式でテスト自動化の構築が容易です。
- スクリプト(JavaScript)ベースのコード方式も一緒に提供します。
- 各イベントに対して追加の条件(AI, Script)を追加してデータ検証機能を強化します。
- 各イベントごとに成功条件の追加および失敗復旧スクリプトの設定が可能です。
- 実行前の待機時間の付与および変数名の指定機能を提供します。

### 2.2 Test Executor (自動テスト実行モジュール)

**技術**: Playwright MCP (Multi-Channel Platform) を連携して使用します。

**機能**:

- 自動実行スクリプトが生成され、実際のブラウザ自動化環境でテストを実行します。
- マルチブラウザ自動化環境での並列テスト実行をサポートし、迅速な結果の導出が可能です。
- Chrome、Firefox、Edgeなど多様なブラウザでのクロスブラウザ互換性をサポートし、Safariブラウザの追加もリクエストされています。
- 実行結果レポート(パス/フェイルのログ、スクリーンショットなど)を提供し、失敗したテストケースは自動でロギングされます。
- テスト実行中にエラーが発生した際、ユーザーフレンドリーなエラー識別および診断機能を提供します。エラー発生箇所のスクリーンショット、エラー発生時の録画画面(映像)の提供、そしてユーザーフレンドリーなエラーメッセージを表示します。ダッシュボードでエラーをクリックすると、エラー当時の録画画面を映像で見せます。

### 2.3 ダッシュボード/管理システム

**機能**: シナリオの登録状況、実行状況、エラー状況、ブラウザ情報など、システムモニタリングが可能なダッシュボードを提供します。

**レポート(Report)**:

- 実行結果の視覚化、テストトレンド分析を含む精密なレポートおよび分析を提供し、顧客要件に合わせたカスタムレポートの提供が可能です。
- メールテンプレートでレポートを送信し、ダッシュボードで画像の確認が可能ですがレポートには含まれません。

**シナリオ管理機能**:

- 保存されたシナリオの分類、検索、バージョン管理が可能です。
- 録画時点のデータ記録および修正履歴に対するバージョン管理表示をサポートします。
- 顧客の要求に合わせてテストシナリオの抽出が可能です。
- シナリオ履歴のフィルタリングにより、実行履歴の管理の利便性を提供します。
- UIの変化を検知した際に自動的にテスト失敗として処理し、パブリッシングおよびUI変更の検証作業に最適化されます。

### 2.4 データセット (Data Set) 管理機能

**機能**:

- 表形式でデータを入力および管理でき、変数の追加、修正、削除をサポートします。
- シナリオで設定した変数値を呼び出して直接作成したり、AIを活用してモックアップデータを自動的に生成して多様な値でテストを進めることができます。この機能はテストデータを生成するものであり、テストケースのAI自動生成とは区別されます。
- データセットの適用により、多様なケースのテストが可能です。
- 検証データの設定: サイト(プロジェクト)の固有の値の設定を通じて、より高い正確性を付与してデータを検証します。

### 2.5 シナリオ管理および実行オプション

- **Record**: ユーザーのイベントおよびDOM情報を記録する基本単位です。
- **Scenario**: レコード情報を体系的に統合し、テストシナリオを具現化する核心構成要素です。自動およびAIベースの検証を通じて、正確性、安定性、リアルタイムの状態情報による実行結果の追跡が可能です。
- **Collection**: 複数のシナリオを選択して順次実行する機能で、多様なシナリオを柔軟に組み合わせて一貫したワークフローを保証します。1つのシナリオを複数のブラウザで実行させるにはコレクションで実行できます。
- **Story**: フローチャート(Flow Chart)インターフェースを通じてシナリオを自由に接続し、検証結果に基づいて次のシナリオを動的に実行する機能です。視覚的なワークフローと自動検証により、安定性と効率性を保証します。
- **動的テスト Chaining**: 条件による連鎖的なシナリオ実行を通じて柔軟なテストが可能です。
- **再実行時の初期化**: テストの再実行時に環境の初期化機能を提供します。
- **シナリオの深刻度設定**: シナリオごとの重要度管理をサポートします。
- **データを変更して多様な環境で実行可能であり、直列/並列でパフォーマンステストが可能です。

## 3. システム運用および実装の詳細

- **リアルタイム通信**: ソケット通信を通じてリアルタイムのイベント動作およびDOM情報の確認が可能です。
- **画面検証**: AIを通じて各イベントに対する画面キャプチャ後、データの追加検証が可能です。
- **CI/CD連携**: Jenkins、Git、Azure、DevOpsなどCI/CDパイプラインおよび多様な外部ツール/システムとシームレスに連携します。これにより、既存の開発/デプロイプロセスにテスト自動化を自然に統合し、ソフトウェア開発ライフサイクル全体の効率性と品質を向上させることができます。
- **セキュリティおよび認証処理**: 自動ログイン処理、Cookieおよびセッション管理機能の提供、HTTP認証のバイパス可能、VPN、プロキシ設定のサポートなど、多様なセキュリティおよび認証処理機能を含みます。
- **再利用性および保守の容易性**: モジュール化および再利用可能なテスト構造により、テスト資産の再利用と保守効率を高めます。

## 4. 期待効果 (テストケース生成および学習に対する効果は除く)

- **QAリソースの効率化**: 反復的なテスト作業が自動化され、QA業務の効率が増大し、QAリソースが30%以上削減されます。
- **迅速なリリースおよび市場投入**: 回帰テストの自動化を通じて開発サイクルを短縮し、迅速なフィードバックにより市場投入までの時間を早めます。
- **コード作成のないテスト自動化**: 直感的なGUIおよびキーワードベースの非コード方式で、開発知識が不足しているユーザーでも簡単にテスト自動化を構築できます。
- **柔軟なテスト環境の提供**: クロスブラウザの互換性、並列実行、動的チェイニングなど多様な実行オプションとカスタマイズをサポートします。顧客の要求に合わせてテスト環境および機能を柔軟に調整し拡張できるように設計されています。
- **ユーザーフレンドリーなエラー識別**: エラー発生時、ユーザーフレンドリーなエラーメッセージの提供、スクリーンショットの記録、エラー発生時の録画画面の提供などを通じてエラー分析を容易にします。
- **テスト実行のアクセシビリティおよび効率性増大**: 既存のシナリオ録画過程なしにExcelテストケースを直接実行できるようにすることで、QAエンジニアが柔軟にテストを遂行し時間を節約できます。
- **テストの品質および信頼性の向上**: 人為的ミスを防ぎ一貫した品質を維持します。エラーを早期に発見し、継続的かつ安定した品質を保証します。
