현재 페이지

SyncETAに関する用語集は以下の通りです。

  • Collection (コレクション): 複数のシナリオを選択して順次実行する機能で、多様なシナリオをユーザーのニーズに合わせて柔軟に組み合わせ、一貫したワークフローを保証します。1つのシナリオを複数のブラウザで実行させたい場合は、コレクションとして実行できます。
  • CI/CD (継続的インテグレーション/継続的デプロイ): 開発およびデプロイパイプラインにテスト自動化を自然に統合し、ソフトウェア開発ライフサイクル全体の効率性と品質を向上させることをサポートします。Jenkins、Git、Azure、DevOpsなどの多様な外部ツール/システムとシームレスに連携します。CI/CDの連携により、継続的で安定した品質管理を保証し、開発プロセスの最適化に貢献します。
  • Data Set (データセット): 表形式でデータを入力・管理する機能で、変数の追加、修正、削除をサポートします。シナリオで設定した変数値を呼び出して直接作成したり、AIを活用してモックアップデータを自動生成し、多様な値でテストを進めることができます。
  • LLM (大規模言語モデル): 記録されたユーザー操作シナリオを自然言語ベースのテストケースに変換するために活用される技術です。SyncETAは7BやMistralなどのオープンソースLLMを使用し、QAのフィードバックを反映させることで、LLMのテストケース生成品質を継続的に向上させます。
  • Playwright MCP: SyncETAの自動テスト実行モジュールで使用される技術で、QAが承認したテストケースに基づいて自動実行スクリプトを生成し、マルチブラウザ自動化環境での並列テスト実行をサポートします。Chrome、Firefox、Edgeなど多様なブラウザの互換性を提供し、Safariブラウザの追加もリクエストされています。
  • QA (品質保証): ソフトウェア開発の過程で品質を保証し、効率を最大化する業務を遂行します。SyncETAはQAエンジニアを含むすべてのユーザーが簡単にテスト自動化を構築できるように支援し、生成されたExcelテストケースを直接レビューおよび修正できる機能を提供します。QAのフィードバックはLLMの学習に反映され、テストケース生成品質の向上に貢献します。
  • QA Feedback Loop (品質改善ループ): QAエンジニアが生成されたExcelテストケースをレビューして修正すると、この修正されたデータがSyncETAシステムにアップロードされ、LLMの学習データとして活用されます。これにより、テストケース生成品質が継続的に向上し、時間の経過とともに自動生成テストケースの信頼性とテストカバレッジが増加します。
  • Record (レコード): ユーザーのイベントおよびDOM情報を記録する基本単位です。クリック、入力、スクロール、ページ遷移など、Webブラウザ内のユーザーの実際の動作を、URL、XPath、クラス、ID、タブ情報などと共にリアルタイムにキャプチャして記録します。
  • 回帰テスト自動化 (Regression Test Automation): 開発サイクルの短縮による反復的なテストの負担を軽減し、ソフトウェアの品質を継続的に管理するための自動化システムおよび方法です。SyncETAはこれにより開発サイクルを短縮し、迅速なフィードバックにより市場投入までの時間を早める効果を提供します。
  • Scenario (シナリオ): レコード情報を体系的に統合し、テストシナリオを具現化する核心的な構成要素です。ユーザー定義のイベントを指定された順序で実行し、自動およびAIベースの検証を通じて、正確性、安定性、リアルタイムの状態情報による実行結果の追跡が可能です。
  • Selenium (セレニウム): SyncETA Recorder (ユーザー行動録画モジュール)で使用される技術で、ユーザーのWebブラウザの動作をリアルタイムにキャプチャし、JSON/YAMLベースのフォーマットのテストシナリオとして自動生成および保存します。Web自動化およびテスティングのための強力で使いやすいフレームワークです。
  • Story (ストーリー): フローチャート(Flow Chart)インターフェースを通じてシナリオを自由に接続し、検証結果に基づいて次のシナリオを動的に実行するSyncETAの重要な機能の1つです。視覚的なワークフローと自動検証により、安定性と効率性を保証します。
  • SyncETA (シンクエタ): AI基盤の自然言語テストケース生成によるWebブラウザ動作レコーディングおよび自動テスト実行システムおよび方法です。Selenium基盤のブラウザ動作レコーディングとAI基盤のテストケース生成を組み合わせた革新的なテスト自動化ソリューションであり、QA業務の効率性とソフトウェア品質を最大化することを目標としています。End to end test automationの略語であり、Dockerベースのインストール型(On-premise)またはクラウドSaaS形式でデプロイできます。
  • SyncETA Recorder (ユーザー行動録画モジュール): Selenium技術を使用して、実際のユーザーのブラウザ内での動作(クリック、入力、スクロール、ページ移動、タブ情報など)をリアルタイムに録画し、イベントおよびDOM情報を記録します。録画された動作は、JSON/YAMLベースのフォーマットのテストシナリオとして保存されます。
  • Test Executor (自動テスト実行モジュール): TestCase Generatorを通じて生成され、QAが検証したExcelテストケースに基づいて自動実行スクリプトを生成し、実際のブラウザ自動化環境でテストを実行します。Playwright MCPを活用し、並列テスト実行およびクロスブラウザ互換性をサポートします。
  • TestCase Generator (自然言語テストケース自動生成モジュール): SyncETA Recorderで生成されたJSON形式のテストシナリオを入力として受け取り、LLMがこれを分析して、人が読みやすい自然言語ベースのExcelテストケースを自動生成するモジュールです。Step、Input、Expected Resultなどを含むテストケースを生成し、再利用可能なテンプレート形式で提供される場合があります。
  • テストケース (Test Case): SyncETAシステムでAI (LLM)を通じて自然言語基盤(主にExcel形式)で自動生成されるテストシナリオドキュメントです。Step、Input、Expected Resultなどのフィールドを含み、QAエンジニアによって検証および修正することができます。
  • クロスブラウザ互換性 (Cross-browser Compatibility): 1台のPCから複数のブラウザで同時テストが可能になるようにサポートする機能で、Chrome、Firefox、Edgeなど多様なブラウザでの互換性をサポートします。
  • コード作成のないテスト自動化 (No-code/Low-code Test Automation): 開発知識が不足しているユーザーでも、直感的なGUIおよびキーワードベースの非コード方式で簡単にテスト自動化を構築できるようにするSyncETAの強みです。既存の開発知識要求の問題を解決し、非技術ユーザー(QAチーム)のアクセシビリティを高めます。
  • エラーの識別と診断 (Error Identification & Diagnosis): テスト実行中にエラーが発生した際、ユーザーフレンドリーなエラーメッセージの提供、スクリーンショットの記録、エラー発生当時の録画画面(映像)の提供などを通じて、エラー分析を容易にする機能です。
  • ダッシュボード/管理システム (Dashboard/Management System): シナリオの登録状況、実行状況、エラー状況などシステムモニタリングが可能なインターフェースを提供します。実行履歴からの映像確認、エラーレコードのスクリーンショットと録画画面の提供などを通じてエラー分析を支援します。
