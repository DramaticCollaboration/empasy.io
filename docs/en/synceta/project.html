Project & RBAC Management ​

A 'Project' is the top-level boundary for isolating scenarios, datasets, execution histories, and reports.

1. Creating Projects ​

Create projects from the dashboard toolbar, project list, or initial welcome screen.

2. Role-Based Access Control (RBAC) ​

Define custom roles and allocate permissions (scenario edit, run tests, manage datasets, generate API keys).

3. Member Invitations ​

Invite team members by email and assign project-level roles.
