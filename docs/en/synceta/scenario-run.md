# Scenario Execution & Scheduler

Execute single scenarios on-demand, run high-concurrency suites across multiple browser engines, or schedule recurring regression runs.

---

## 1. Direct Execution Options

Click **'Run'** in the scenario view to open execution parameters.

![Run Settings](./image/scenario-run/runsetting.png)

### Key Parameters
- **Browser Engine**: Chromium, Chrome, Microsoft Edge, Firefox, WebKit
- **Resolution**: 1920x1080 (Desktop), tablet, or mobile viewports
- **Execution Mode**: Sequential or Parallel instances
- **Headless Mode**: High-speed background execution
- **Video Capture**: Records full execution sessions to MP4
