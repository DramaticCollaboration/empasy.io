# SyncETA Test Case Generation and Learning Module Detailed Specifications

This document details the hardware and software specifications focusing on natural language-based test case generation using a Large Language Model (LLM), LLM learning through QA feedback, and its quality improvement among SyncETA's regression test automation solutions.

## 1. System Overview (Focusing on Test Case Generation and Learning)

SyncETA automates scenarios through user browser action recording based on Selenium and converts them into Excel-format test cases with LLM-based natural language processing technology. The generated test cases undergo a verification and modification process by QA engineers, and QA's feedback is reflected in the LLM's learning to continuously improve the quality of test case generation. Ultimately, it aims to maximize QA work efficiency and software quality.

## 2. Software Detailed Specifications

The key software modules related to SyncETA's test case generation and learning are as follows.

### 2.1. TestCase Generator (Natural Language Test Case Auto-Generation Module)

**Technology**: Utilizes open-source LLMs.

**Input**: Receives JSON format test scenario data generated by the SyncETA Recorder.

**Output**:

- The LLM analyzes the input JSON scenario and automatically generates a natural language-based Excel test case including Step, Input, Expected Result, etc.
- The generated Excel test cases can be provided in the form of reusable templates.

**Key Features and Learning**:

- Context learning about in-house terminology and UI elements is possible. Through this, the LLM can understand unique expressions of specific business domains or services and reflect them in test case generation.
- Supports format customizing tailored to QA standards. This enables flexible test case output that fits the QA team's existing workflow and report formats.
- Automatically writes test objectives, steps, and expected results in a structured format.

### 2.2. QA Feedback Loop (Quality Improvement Loop Module)

**Features**:

- QA engineers can directly review and modify Excel test cases generated through the TestCase Generator.
- Optimization tasks such as supplementing incomplete cases, removing duplicate cases, and prioritizing are possible.
- Data modified or evaluated by QA is uploaded to the SyncETA system.

**Learning Reflection and Quality Improvement Loop**:

- Uploaded QA modification data is reflected in the LLM's re-training (Fine-tuning or RAG, Retrieval-Augmented Generation). Test case generation quality improves through this continuous learning process.
- Secures LLM training data based on QA's modifications and continuously improves test case generation accuracy and coverage through periodic re-training.
- Over time, the reliability of auto-generated test cases increases and test coverage improves.
- You can monitor the learning effect by providing QA feedback history analysis and improvement history tracking features.

### 2.3. Dataset Management Feature (AI Utilization Part)

**Features**:

- Can input and manage data in a tabular format, supporting the addition, modification, and deletion of variables.
- You can write directly by calling variable values set in the scenario, and automatically generate mockup data using AI to conduct tests with various values. This feature is for AI to generate data to be used in the test, which is separate from the AI generation of the test case itself.

## 3. Hardware Detailed Specifications (Related to LLM Operation)

SyncETA supports the following deployment environments for the flexible operation of LLM models.

**Deployment Format**: SyncETA can be deployed as a Docker-based installation (On-premise) or as a Cloud SaaS (Software as a Service) format.

**Security Requirements**: Depending on security requirements, it supports executing LLM models directly in an On-premise environment. This can strengthen security by lowering dependence on external cloud LLM services when processing sensitive data.

## 4. Expected Effects (Related to Test Case Generation and Learning)

SyncETA's test case generation and learning features provide the following key expected effects:

- **Reduce test case writing time by 80%**: Drastically shortens test case writing time compared to manual work through Selenium recording and LLM-based automatic generation.
- **Streamline QA Resources**: Repetitive test case writing tasks are automated through AI-based test case generation and the QA feedback loop, increasing QA work efficiency and reducing QA resources by more than 30%. QA personnel can save time by focusing on verifying automatically generated cases.
- **Improve Test Quality and Reliability**: Through AI-based test case generation and the QA feedback loop, test accuracy and coverage improve, preventing human errors and maintaining consistent quality. Test coverage is improved by the LLM's intelligent case generation.
- **Test Automation without Writing Code**: Uses an intuitive GUI and keyword-based non-code methods, allowing users lacking development knowledge (QA teams) to easily build test automation. In particular, accessibility is high as natural language-based test cases can be generated through LLMs.
- **Continuous Quality Improvement**: Continuously improves test case generation quality by training the LLM with QA feedback data, providing a more accurate and reliable test automation environment.
