## 📚 Scrumban Glossary of Terms

| Category | Korean | English | Abbreviation | Description |
| --------- | ------------------ | ----------------------- | ---- | ------------------------------------------------------------------------------- |
| Basic Concept | 스크럼반 | Scrumban | - | An agile project management framework combining the advantages of Scrum and Kanban |
| Basic Concept | 스크럼 | Scrum | - | Agile development methodology centered around iteration and sprints |
| Basic Concept | 칸반 | Kanban | - | A project management technique that visualizes workflow and limits Work In Progress (WIP) |
| Basic Concept | 애자일 | Agile | - | A set of philosophies and methodologies for developing products in a flexible and iterative manner |
| Unit of Work | 작업 항목 | Work Item | - | A specific unit of work that the team needs to perform |
| Unit of Work | 사용자 스토리 | User Story | - | A unit of work expressing user requirements in a simple story format |
| Unit of Work | 태스크 | Task | - | A detailed execution item broken down from a user story or work |
| Board Structure | 백로그 | Backlog | - | A list of all work items that have not yet been started |
| Board Structure | 준비됨 | Ready | - | The state of a work item that is ready to be started |
| Board Structure | 진행 중 | In Progress | - | The state where work is currently underway |
| Board Structure | 검토 중 | Review | - | The state where completed work is waiting for a quality review |
| Board Structure | 완료 | Done | - | The state where all reviews are passed and it is ready for deployment |
| Operation Rule | 진행 중 작업 제한 | Work In Progress Limit | WIP | The maximum number of work items that can be processed simultaneously |
| Operation Rule | 리드 타임 | Lead Time | - | The total time from when a work request is generated until it is completed |
| Operation Rule | 사이클 타임 | Cycle Time | - | The time taken from the start of work until it is completed |
| Operation Rule | 플로우 효율성 | Flow Efficiency | - | The ratio of time actually spent working to the total time the work is in progress |
| Event | 데일리 스탠드업 | Daily Stand-up | - | A short daily meeting for sharing team progress |
| Event | 스프린트 계획 회의 | Sprint Planning Meeting | - | A meeting to plan the work to be done in the next sprint |
| Event | 리뷰 회의 | Review Meeting | - | A meeting to review completed work and receive feedback |
| Event | 회고 | Retrospective | - | A process improvement meeting held by the team at regular intervals |
| Metric | 번다운 차트 | Burndown Chart | - | A chart visualizing the remaining amount of work over time |
| Metric | 누적 흐름도 | Cumulative Flow Diagram | CFD | A chart that visualizes changes in cumulative items by work state to identify bottlenecks |
