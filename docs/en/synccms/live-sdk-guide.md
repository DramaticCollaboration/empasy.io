# Sync-Live-SDK Integration Guide

With **Sync-Live-SDK**, marketers and editors can visually click and modify text and banners directly on live production web/app screens without logging into the backoffice.

```html
<!-- Embed 1 line in your frontend HTML -->
<script src="https://cms.empasy.com/sdk/sync-live-sdk.js" 
        data-sync-cms-endpoint="https://cms.empasy.com/api/v1"
        data-sync-site-key="YOUR_SITE_KEY" async></script>
```
